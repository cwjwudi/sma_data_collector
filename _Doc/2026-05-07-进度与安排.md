## 📋 工业自动化数据管理工具

本平台是一个集数据采集、实时监控与自动化报表于一体的集成化工具体系，旨在打通 PLC 底层硬件与上位机管理软件之间的信息链路。

### 1. 软件功能模块介绍


| **模块名称**         | **技术栈**                                                                                                                                                      | **核心功能描述**                                                                                                                                                                                                                                                                                                                                                                      |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **OPCUA 数据采集程序** | Python / Asyncio                                                                                                                                             | 负责与 PLC 通讯。 利用 OPCUA 协议实时订阅/轮询底层寄存器数据，并将其结构化后存入本地数据库。 支持断线自动重连。                                                                                                                                                                                                                                                                                                                 |
| **数据可视化 Web 平台** | Python / FastAPI                                                                                                                                             | 基于 WebViewer 嵌入式设计。 提供数据查询、历史趋势展示。 支持插件化扩展，不同功能组（如 Alarm）可动态绑定至独立页面。                                                                                                                                                                                                                                                                                                            |

### 3. 软件组织与运维架构

为了确保在 Windows 工业电脑上的稳定性，后续系统采用以下组织方式：

- **进程托管**：所有程序通过 **NSSM** 注册为 Windows 系统服务，实现开机自启与崩溃自愈。
- **统一存储**：数据库、程序文件与日志文件集中存储于 `C:\Industrial_Platform\`，便于一键备份。
- **隔离运行**：采用嵌入式 Python 虚拟环境，确保各程序依赖库互不干扰。
