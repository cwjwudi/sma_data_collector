# SD SMA 轻量安装包构建说明

## 目标

客户只接触一个 Inno Setup 安装程序和一个 `SD_SMA_Launcher.exe` 启动入口。四个 FastAPI 服务继续作为四个独立进程运行，但共同使用安装目录中的一份 Python 3.10–3.12 运行时和一份第三方依赖，不创建四个虚拟环境。

## 交付结构

```text
SD SMA/
  _Launcher/
    SD_SMA_Launcher.exe
    launcher_config.json
    start.bat
    stop.bat
  .venv/                  # 四个服务共享的一份依赖环境
  _Python/                # .venv 对应的一份 Python 基础运行时
  _Prj/                   # 仅交付 .pyc，不交付本项目 .py 源码
  config/
  logs/
  start.bat
```

Nuitka 只编译公开的 Launcher 入口。四个服务使用 Python 3.12 legacy-layout `.pyc`，从而兼顾体积、现有动态 `uvicorn module:app` 加载方式和基础源码隐藏。HTML、JavaScript、CSS 以及需要现场修改的 JSON 配置仍保持为外部文件。

## 构建命令

双击 `_Launcher\build.bat` 后使用英文菜单选择：

```text
1. Build installer package
2. Build source package
```

也可以直接执行 `_Launcher\build.bat installer` 或 `_Launcher\build.bat source`。无论当前目录是仓库根目录还是 `_Launcher`，输出路径都以仓库根目录为基准。

可选参数直接传给 PowerShell 构建脚本，例如：

```bat
_Launcher\build.bat installer -Version 1.0.0 -SkipSmokeTest
```

默认输出：

```text
_Build\SD_SMA_Installer_Package\SD_SMA_Setup_1.0.0.exe
```

Installer 模式产生的运行时 staging 和 Nuitka 中间产物也统一位于 `_Build\SD_SMA_Installer_Package\`，不会散落到 `_Build` 的其他子目录。
构建时会清理旧版的 `_Build\Installer`、`_Build\Nuitka_Launcher` 和 `_Build\SD_SMA_Installer_Staging` 输出目录。

构建机要求：

- Python 3.10–3.12；优先使用仓库 `.venv`。
- `uv`；Nuitka 缺失时构建脚本使用 `uv` 安装到构建环境。
- Inno Setup 6；可使用 `winget install --id JRSoftware.InnoSetup --exact` 安装。

## 构建过程

1. 复用现有便携包脚本生成一份共享 Python 运行环境。所有 `_Prj/<项目>/config` 均不复制；包根 `config/<service>/` 只允许复制仓库根对应目录中的 `default.json`，不存在 `default.json` 时保留空目录。
2. 删除四个服务中的测试、开发文档、工具脚本、缓存以及采集器本机队列数据库；现场运行时按需重新创建空队列。DB Admin 仅保留 `mariadb.exe` 和 `mariadb-dump.exe`，不携带完整 MariaDB 开发目录。
3. 使用交付包自身的 Python 将项目 `.py` 编译成相邻 `.pyc`，确认全部成功后删除项目 `.py`。
4. 使用 Nuitka onefile 编译 `SD_SMA_Launcher.exe`，源码模式和编译模式使用同一套路径解析。
5. 使用编译后的 Launcher 对字节码服务执行四服务 smoke test；测试成功后再次删除自动生成的活动配置标记和测试日志，确保最终 config 仍只有 `default.json`。
6. 使用 Inno Setup 生成单 EXE 安装程序。

## 安全与维护边界

- `.pyc` 是轻量隐藏，不是高强度防逆向；符合当前“避免客户直接看到源代码”的目标。
- 第三方库可能仍包含自身的 `.py`，这些不是 SD SMA 项目源码。
- 配置和日志必须保持可写，因此默认按当前 Windows 用户安装到 `%LOCALAPPDATA%\Programs\SmartData\SD SMA`。
- 调试交付问题时仍可使用 `_Launcher\build.bat portable` 生成保留源码的内部便携包。
