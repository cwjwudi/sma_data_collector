# ✅ 已完成：组外部启停与顶部操作反馈

## 目标

- 点位列表较长时，加入 points、校验、保存等操作仍能立即看到结果。
- 每个 group 可选配外部 OPC UA 点位：`1/True` 启用，`0/False` 停用；未配置时一直启用。

## 实现

- 操作反馈移动到“采集配置”标题下方，并在容器顶部粘附；提供成功、错误、信息三种状态及 `role=status`、`aria-live=polite`。
- 点位加入成功后显示点名和当前 points 总数，按钮同步变为“已加入 ✓”。
- 新增可选配置 `groups[].enable_point`，引用 `points[].name`，加载时校验引用存在。
- 运行时每秒读取启用点：`1/True` 启动组任务，`0/False` 取消组任务，恢复为 1 后自动重启。
- 无效值或临时读取失败保持上一有效状态；启动后尚无有效状态时保持停用。
- Demo PLC 的 `gDataSQLOperate` 新增六个默认 TRUE 的 BOOL 控制点，并由现有 OPC UA 映射公开。

## 验收

- 浏览器实测：加载、校验、加入点位的顶部反馈均可见；六个 group 均显示“外部启用点位”，未配置时显示“一直启用”。测试加入仅发生在页面内存，未保存覆盖 `AA_test.json`。
- Automation Studio 4 构建：0 error、1 个与本次修改无关的 Package 附加脚本目录 warning。
- PLC 下载成功；最终探测为 `X20CP1586 / J4.93 / WarmStart`，六个新 OPC UA 点位读值均为 `true`。
- 自动化回归：`199 passed, 4 warnings`；新增外部启停专项测试 19 项。
- 真实 PLC/MySQL 冒烟测试：77.875 秒，3 个停用窗口全部零误采且恢复成功。
- 一小时稳定性测试：3608.188 秒，30 个停用窗口全部零误采且恢复成功；六组数据库新增行数分别为 Recipe 111、Product 3230、Alarm 533、Audit 390、Batch 38、BatchInfo 163。
