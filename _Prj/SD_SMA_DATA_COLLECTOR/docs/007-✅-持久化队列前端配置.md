# ✅ 已完成：持久化队列前端配置

## 问题

后端已支持 `persistent_queue`，但 Web 配置页没有对应入口，并且配置管理器的顶层字段白名单未包含该字段。通过页面加载和保存配置时，已有的持久化队列配置可能被过滤掉。

## 实现

- 将 `persistent_queue` 加入 Web 配置管理器允许的顶层字段并提供完整默认值。
- 在“数据库”页签增加“启用 SQLite 持久化队列”开关。
- 启用后可编辑 outbox 路径、SQLite 同步级别、忙等待超时、租约、重试间隔、最大重试次数、记录保留时间、清理间隔和最大队列行数。
- 未启用时明确提示未满批次数据仅保存在内存中。
- 加载、校验和保存配置时完整保留 `persistent_queue`。

## 验证

- Web 配置管理器专项测试覆盖默认值、字段保留、校验、写入和重新加载。
- JavaScript 语法检查和完整 Python 回归测试通过。
