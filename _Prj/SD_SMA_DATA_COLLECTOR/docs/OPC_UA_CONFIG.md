# OPC UA 通信配置说明

## 新增功能

本版本增加了对OPC UA服务器IP地址和端口的灵活配置支持。

## 配置方式

在配置文件中添加 `opcua` 节点来指定OPC UA服务器的连接信息：

```json
{
  "opcua": {
    "host": "127.0.0.1",
    "port": 4840
  },
  "points": [...],
  "groups": [...],
  "database": {...}
}
```

## 配置参数说明

### opcua 配置项

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| host | string | "127.0.0.1" | OPC UA服务器IP地址 |
| port | integer | 4840 | OPC UA服务器端口号 |

## 使用示例

### 1. 本地服务器（默认配置）
```json
{
  "opcua": {
    "host": "127.0.0.1",
    "port": 4840
  }
}
```

### 2. 远程服务器
```json
{
  "opcua": {
    "host": "192.168.1.100",
    "port": 4840
  }
}
```

### 3. 自定义端口
```json
{
  "opcua": {
    "host": "127.0.0.1",
    "port": 4841
  }
}
```

## 注意事项

1. **向后兼容性**：如果配置文件中没有 `opcua` 节点，系统将使用默认值（127.0.0.1:4840）
2. **配置验证**：系统会自动验证配置格式的正确性
3. **连接测试**：启动时会测试OPC UA服务器连接，连接失败会有相应错误提示

## 配置文件示例

完整的配置文件示例请参考：
- `config/sample_config.json` - 默认配置示例
- `config/test_config_custom_opc.json` - 自定义配置示例

## 故障排除

如果遇到连接问题，请检查：
1. OPC UA服务器是否正在运行
2. IP地址和端口号是否正确
3. 网络防火墙设置
4. 服务器是否允许外部连接
