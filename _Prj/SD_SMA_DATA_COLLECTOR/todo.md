# SD SMA Data Collector 变更索引

## 2026-07-22

- **采集组关闭立即刷新缓存**：外部启用信号从 1 切换为 0 时，先停止该组采集，再由存储循环立即提交该组未满批缓存；数据库失败时保留数据和刷新请求继续重试。完整回归 `204 passed`，真实 PLC/MySQL 稳定性测试 `3608.188s`，30 个关闭窗口共刷新 3072 行，最大延迟 1.047 秒，失败/死信/残留均为 0。详见 [docs/008-✅-采集组关闭立即刷新缓存.md](docs/008-✅-采集组关闭立即刷新缓存.md)。

- **持久化队列前端配置**：数据库页签新增持久化队列开关和完整参数编辑；修复 Web 配置管理器过滤 `persistent_queue` 导致加载后保存丢失配置的问题。详见 [docs/007-✅-持久化队列前端配置.md](docs/007-✅-持久化队列前端配置.md)。
