查询页 · 配置页
服务启动与 OPC 回写均使用此配置（写入 .active_query_config）

配置文件

选择一个完整 config 文件进行加载；每个文件包含基础设置、查询视图和插件页面配置。

基础设定

数据库与查询限制写入 app_settings；OPC UA 连接写入 profile 顶层 opcua。点「保存基础设定」一并保存。

数据库连接

MySQL / SQLite 连接参数（app_settings.database）

查询限制

API 限流与时间窗口（app_settings.query_limits）

OPC UA 连接

分别填写 PLC 的 IP 与端口（无需写 opc.tcp:// 前缀）；插件页回写共用此连接（profile.opcua）

留空默认 127.0.0.1:4840

Group 与列

配置各表的时间字段、列顺序、排序、分页与列中英文显示名；仅在查询中引用已配置的组。

可选列
查询列顺序（最终生效）
列显示名编辑

插件页面

用于 /plugins/{module}_{1-5}.html 动态绑定；每模块预留 1–5 页。

OPC UA 回写

勾选需要回写的列并填写 NodeId（B&R 示例：ns=6;s=::DataRev:strStartTime）； 仅白名单列写入 PLC 数组（最长 50）。全局 Endpoint 在「基础设定」中配置。

翻页/查询后写 -1；点击行写 0–49
高级 · opcua_writeback JSON 预览

只读预览，由上方表单生成；保存当前页配置时以表单为准。 columns 键为数据库字段名，未列出的列不会写 PLC。

批次表名回写

绑定批次主表时启用。基础模式根据 diCursor 选中行写表名数组；高级模式由 PLC OPC UA 上升沿触发翻页与回写。

可选；不选则按批次号反查主表

高级 · OPC UA 节点

上一页/下一页绑定两个 BOOL 节点（上升沿触发，与插件页翻页一致）；批次号节点接收 PLC 字符串；触发节点上升沿时按批次号回写 Buffer。

高级 · table_list_writeback JSON 预览

只读预览；保存当前页配置时以表单为准，可在此复制后手动合并高级字段。
