# SD SMA Report Copy

本地报表复制小程序，用于在 Windows 10 上浏览配置的 `SMA_Report` 报表目录，预览 PDF，并将选中的报表复制到 U 盘。

默认统一启动器地址：

- `http://127.0.0.1:8094/`

## 功能

- 配置报表源目录，默认 `D:/SMA_Report`
- 列出 PDF 报表，支持搜索、全选、多选文件，以及按文件夹多选后递归复制
- 使用浏览器原生 PDF 能力预览报表
- 检测 Windows 可移动磁盘，并复制到 U 盘中的 `SMA_Report` 目录
- 同名文件默认跳过，可手动选择覆盖
- 后台复制任务、进度、日志

## 安全边界

- 服务只由统一启动器绑定 `127.0.0.1`
- 前端只提交报表相对路径，后端限制源文件必须位于配置的报表目录内
- 目标默认只允许可移动磁盘；如现场移动硬盘被识别为固定磁盘，可在页面配置允许盘符
- 不提供删除源文件功能

## 手动启动

```bat
python -m uvicorn app.main:app --host 127.0.0.1 --port 8094
```
