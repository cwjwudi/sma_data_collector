### 4.2 启动方式

#### 方式一：Electron 桌面模式（推荐，一键启动）

```cmd
cd /d D:\002_Project\999_BRTeam\_proj\P000_SD_SMA_SCADA\_Prj\SD_SMA_ReportEditor\frontend

npm run electron:dev
```

此命令会**同时**启动：
1. Vite 开发服务器 → `http://localhost:5173`
2. Python 后端子进程 → `http://127.0.0.1:8000`（自动检测 venv）
3. Electron 桌面窗口（加载前端页面 + DevTools）

关闭窗口时所有进程自动终止。

#### 方式二：分别启动（调试用）

**启动后端：**

```cmd
cd /d D:\002_Project\999_BRTeam\_proj\P000_SD_SMA_SCADA\_Prj\SD_SMA_ReportEditor\backend

.\venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

**启动前端（浏览器模式）：**

```cmd
cd /d D:\002_Project\999_BRTeam\_proj\P000_SD_SMA_SCADA\_Prj\SD_SMA_ReportEditor\frontend

npm run dev
```

然后浏览器打开 `http://localhost:5173`。

## 五、架构说明

### 5.1 通信架构

```
┌─────────────────────────────────────────────────┐
│                 Electron 主进程                    │
│   electron/main.js                               │
│   ├── spawn Python 子进程（uvicorn）               │
│   ├── 健康轮询 /health 等待后端就绪                  │
│   └── 创建 BrowserWindow 加载前端                   │
├─────────────────────────────────────────────────┤
│           BrowserWindow（渲染进程）                 │
│   ┌─────────────────────────────────────────┐   │
│   │        Vue 3 前端（Vite 构建）             │   │
│   │   localhost:5173（开发） / dist/（生产）    │   │
│   │                                         │   │
│   │   前端 fetch('/api/xxx')                 │   │
│   │        │                                │   │
│   │        ▼  Vite proxy 代理               │   │
│   │   127.0.0.1:8000                        │   │
│   └─────────────────────────────────────────┘   │
├─────────────────────────────────────────────────┤
│              FastAPI 后端                        │
│   127.0.0.1:8000                                │
│   ├── config.json（本地配置持久化）                 │
│   ├── SQLAlchemy → MySQL / PostgreSQL            │
│   └── asyncua → OPC UA Server                   │
└─────────────────────────────────────────────────┘
```

### 5.2 前端路由

| 路径 | 页面 | 功能 |
|------|------|------|
| `/` | Dashboard | 仪表盘，快速入口卡片 |
| `/datasource` | DataSourceConfig | 配置数据库连接和 OPC UA 服务器 |
| `/templates` | TemplateManager | 管理报表模板（列表/新建/删除） |
| `/editor/:id?` | TemplateEditor | 可视化编辑模板元素 |
| `/generate` | ReportGenerator | 选择模板生成报表 |
| `/history` | ReportHistory | 查看历史报表 |
| `/settings` | Settings | 全局设置、配置导入导出 |

### 5.3 后端模块规划

| 模块 | 文件 | 职责 |
|------|------|------|
| config_module | `modules/config_module.py` | config.json 读写 |
| db_module | `modules/db_module.py` | 数据库连接管理、探索、SQL 执行 |
| opcua_module | `modules/opcua_module.py` | OPC UA 服务器管理、节点浏览、值读取 |
| template_module | `modules/template_module.py` | 模板 CRUD、JSON 文件持久化 |
| generator_module | `modules/generator_module.py` | 读取数据源 → 渲染模板 → 生成 Markdown |
| history_module | `modules/history_module.py` | 历史报表存储、列表、筛选、导出 |

### 5.4 本地数据存储

所有数据保存在 `backend/data/` 目录，启动时自动创建：

| 路径 | 用途 |
|------|------|
| `data/config.json` | 全局配置（DB 连接列表、OPC UA 服务器列表） |
| `data/templates/*.json` | 各报表模板定义 |
| `data/history/*.md` | 生成的历史报表 |
| `data/history/*.meta.json` | 历史报表的元数据（模板 ID、生成时间等） |

## 六、注意事项

1. `backend/data/` 和 `frontend/node_modules/` 不纳入 Git，由 `.gitignore` 排除
2. `backend/venv/` 不纳入 Git，每台机器需独立创建虚拟环境
3. Electron 内嵌 DevTools 默认关闭，可在「设置 › 开发者工具」中开启（偏好写入 localStorage）
4. Vite 代理规则：前端 `/api/*` 请求会转发到后端 `http://127.0.0.1:8000/*`（去掉 `/api` 前缀）
5. Electron 主进程会自动查找 `backend/venv/Scripts/python.exe`，找不到则回退到系统 `python`
6. npm 镜像已切换为淘宝源（`https://registry.npmmirror.com`），加速国内下载
