# Mac 开发环境准备（Python 3.10+ / Node.js / Electron）

本文记录在本机 **macOS** 上调试 **SD_SMA_ReportEditor** 所需环境、推荐安装方式，以及 **Electron** 启动时的注意点。  
数据库部署在 **群晖 NAS** 时，**无需**在 Mac 上安装 MySQL/PostgreSQL 等数据库软件，只需网络可达并在应用内配置连接即可。

---

## 说明：关于「在 AS 中安装」

若「AS」指 **Android Studio**：本工具是 **Electron + Vue + FastAPI**，并不使用 Android SDK。请在 **macOS 终端**（Terminal、iTerm2）或编辑器内置终端里安装并使用 **Python 与 Node**，与 Android Studio 无绑定关系。

---

## 一、环境需求速查

| 组件 | 版本/要求 | 本机是否必须安装 |
|------|-----------|------------------|
| Python | **3.10 及以上**（项目 README / 依赖要求） | 是（系统自带的 3.9.x 通常不够） |
| Node.js | **建议 LTS**（如 20.x / 22.x），需带 `npm` | 是 |
| 包管理（推荐） | **Homebrew**（便于安装与升级 Python/Node） | 强烈推荐 |
| 数据库 | MySQL/MariaDB/PostgreSQL 等 | **否**（使用群晖 NAS 上实例即可） |
| OPC UA | 可选 | 仅调试 OPC 功能时需要可达的 UA 服务 |

## 二、安装 Homebrew（推荐，二选一）

若已执行 `brew --version` 有输出，可跳过本节。

官方安装（终端执行，按提示输入密码并回车）：

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Apple Silicon 安装结束后，一般需将 brew 加入 PATH（安装脚本末尾会提示，以下为常见写法）：

```bash
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"
```

**不打算用 Homebrew 时**：Python 可使用 [python.org](https://www.python.org/downloads/) 安装包；Node 可使用 [nodejs.org](https://nodejs.org/) 安装包或 [nvm](https://github.com/nvm-sh/nvm)。

## 三、安装 Python 3.10+

### 方式 A：Homebrew

```bash
brew install python@3.12
```

验证：

```bash
python3.12 --version
```

建议在后端目录用 **虚拟环境** 固定版本（勿与系统自带 `python3` 混用）：

```bash
cd /path/to/SD_SMA_ReportEditor/backend
python3.12 -m venv venv
source venv/bin/activate
python --version    # 应显示 3.12.x
pip install -r requirements.txt
```

### 方式 B：pyenv（适合多版本切换）

```bash
brew install pyenv
pyenv install 3.12.8
cd /path/to/SD_SMA_ReportEditor/backend
pyenv local 3.12.8
python -m venv venv && source venv/bin/activate && pip install -r requirements.txt
```

## 四、安装 Node.js（含 npm）

### 方式 A：Homebrew

```bash
brew install node
node --version
npm --version
```

### 方式 B：nvm（推荐需要多版本 Node 时）

```bash
brew install nvm
# 按 brew 提示配置 ~/.zshrc 中的 NVM_DIR 与 nvm.sh
nvm install --lts
nvm use --lts
```

前端依赖：

```bash
cd /path/to/SD_SMA_ReportEditor/frontend
npm install
```

## 五、数据库在群晖 NAS 时的准备

1. **本机**：不强制安装数据库服务端；确保 Mac 能 **ping/访问** NAS（同局域网或 VPN）。
2. **NAS**：在群晖上启用对应服务（MariaDB、PostgreSQL 等），并开放端口、配置防火墙与 **允许远程连接** 的账号权限。
3. **本工具**：在应用 **数据源** 页面填写 NAS 的 **主机名/IP、端口、库名、账号密码**；若仅本机调试，注意部分环境需使用 **NAS 局域网 IP** 而非仅 `localhost`（数据库不在本机时）。

## 六、可运行 Electron 的环境准备

Electron 依赖已写在 `frontend/package.json` 的 `devDependencies`（如 `electron`），通过 **npm** 安装即可，**无需**单独再装一个「Electron 运行时」。

### 1. 安装前端依赖（已包含 Electron）

```bash
cd /path/to/SD_SMA_ReportEditor/frontend
npm install
```

### 2. 开发模式启动 Electron

```bash
npm run electron:dev
```

该脚本会启动 Vite，并在页面可访问后启动 Electron。FastAPI 后端默认由 **Electron 主进程**尝试拉起（见 `frontend/electron/main.cjs`）。

### 3. Mac 上 Electron 拉起后端的注意点

`frontend/electron/main.cjs` 在开发模式下会按顺序查找：

1. `backend/venv/Scripts/python.exe`（Windows）
2. `backend/venv/bin/python3`、`backend/venv/bin/python`（macOS / Linux）

因此请在 **`backend` 下创建并安装好依赖的 venv**（见第三节），再用 `npm run electron:dev`，Electron 一般可直接拉起 FastAPI。

若未创建 venv，会回退为系统命令：Windows 用 `python`，**macOS / Linux 用 `python3`**（需已安装 3.10+ 且在 PATH 中）。

仍失败时：可 **双终端** 手动先起 `uvicorn`，再起 Electron，便于对照终端日志。

验证后端健康：

```bash
curl -s http://127.0.0.1:8000/health
```

## 七、日常调试的两种典型方式

| 方式 | 终端 1（backend） | 终端 2（frontend） | 浏览器 / 桌面 |
|------|-------------------|--------------------|----------------|
| **Web** | `cd backend && source venv/bin/activate && uvicorn main:app --reload --host 127.0.0.1 --port 8000` | `cd frontend && npm run dev` | 浏览器打开 `http://127.0.0.1:5173` |
| **Electron** | 若已建好 `backend/venv`，一般由主进程自动起后端；亦可手动 `uvicorn` 便于看日志 | `cd frontend && npm run electron:dev` | Electron 窗口 |

Windows 仓库里的 `scripts\dev\windows\start_dev_web.bat` 在 Mac 上不适用；Web 调试请用表中命令。

## 八、版本与连通性自检清单

在项目根按顺序执行（路径请换成你本机实际路径）：

```bash
# Python（须在 venv 内或已是 3.10+）
python3 --version
cd SD_SMA_ReportEditor/backend && source venv/bin/activate && python --version && pip --version

# Node
node --version && npm --version

# 后端
uvicorn main:app --host 127.0.0.1 --port 8000
# 另开终端
curl -s http://127.0.0.1:8000/health | head

# 前端
cd ../frontend && npm run dev
# 浏览器访问 http://127.0.0.1:5173

# Electron（按需）
npm run electron:dev
```
