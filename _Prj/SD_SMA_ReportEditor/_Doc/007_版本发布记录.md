# 版本发布记录（CHANGELOG）

> **Report Editor AI（报表编辑器 AI 版）** 桌面版 semver 变更的**唯一完整记录**。发版、写 `latest.json`、对外说明时以本文为准。  
> 里程碑与工单规划见 [002_里程碑与工单.md](002_里程碑与工单.md)；打包步骤见 [packaging/README.md](../packaging/README.md)。

## 维护说明

每次发版请：

1. 在本文**顶部「详细记录」**新增一节（最新版本在最上）。
2. 更新下方**版本一览表**的状态与日期。
3. 执行 `node packaging/scripts/bump-version.mjs <版本> --notes "..."` 同步 `frontend/package.json` 与 `packaging/updates/latest.json` 占位。
4. 打包完成后用 `generate-update-manifest.mjs` 生成 SHA256，写入 `packaging/updates/latest.json` 并同步 Portal（**校验值只维护在 manifest，不在本文重复**）。
5. 在 [002_里程碑与工单.md](002_里程碑与工单.md)「变更记录」追加一行摘要（可选，避免在 002 重复写全文）。

**状态图例：** ✅ 已发布 · 🟡 已打包待 Portal · 📝 开发中 / 草案

**详细记录写法：** 写**变更**与**关联里程碑**即可；安装包文件名、SHA256、大小以 Portal `latest.json` 为准，不在此重复。

**用户数据目录（安装版 · AI 版）：**

| 系统 | 路径 |
|------|------|
| Windows | `%APPDATA%\sd-sma-report-editor-ai\backend-data\` |
| macOS | `~/Library/Application Support/sd-sma-report-editor-ai/backend-data/` |

原版数据目录仍为 `sd-sma-report-editor`（无 `-ai` 后缀），两版可并装；迁移请用 `.rebak` 导入。

## 详细记录

### 0.3.25 🟡

**主题：** 修复模版管理页缩略图卡死

**变更：**
- 根因：0.3.24 在 `ensureTableGrid` / 缩略图渲染路径中每次新建 `resultColumnNameBindings` / `verticalFieldLabelBindings` 数组，触发 Vue 无限响应式更新
- 改为就地对齐绑定数组（保持同一引用与已有元素对象），渲染期可重复调用

**关联里程碑：** M16

### 0.3.24 🟡

**主题：** 列头/左列标签与文本色块 OPC UA 多语言

**变更：**
- SQL 填充「列头名称」「两列表头」「左列标签」「续表分隔文案」可绑 OPC UA；手工文案作空值回退
- 正文/版式「文本」「色块」控件支持 OPC UA 绑定（预览与导出读节点值）
- 收集与导出预检自动纳入新 OPC 节点

**关联里程碑：** M16

### 0.3.23 📝

**主题：** 版式缩略图表格行高修复

**变更：**
- 缩略图表格行改为固定 `height`/`maxHeight`（与版式编辑画布一致）；原先 `height:auto` + `min-height` 在 `<tr>` 上无效，导致行被内容压扁
- 单元格同步写入行高；版式缩略图单元格改为单行裁剪，避免撑破行高

**关联里程碑：** M16

### 0.3.22 🟡

**主题：** 版式缩略图字号与模版一致

**变更：**
- 去掉 0.3.20 的缩略图字号「可读性放大」（缩放约 0.2 时会把字抬到约 40px，导致与模版缩略图比例不符）
- 版式缩略图改用与 `TemplateMiniPage` 相同的字号公式与表格单元格样式

**关联里程碑：** M16

### 0.3.21 🟡

**主题：** 编辑离开前提示是否保存

**变更：**
- 模版编辑器、版式编辑器在有未保存修改时，返回列表或侧栏切换页面会弹出「保存 / 不保存 / 取消」
- 选择「保存」成功后再离开；「不保存」丢弃更改离开；「取消」留在当前编辑页
- 关闭窗口/标签时若有未保存更改，浏览器/Electron 也会给出离开确认

**关联里程碑：** M16

### 0.3.20 🟡

**主题：** 版式列表缩略图显示表格静态文字

**变更：**
- `LayoutPresetMiniPage` 补齐表格分支（复用 `ZoneTableStatic`），左列中文标签等静态单元格可在缩略图中显示
- 页眉/配文字号按缩放补偿，避免缩略图里中文变成细线

**关联里程碑：** M16

### 0.3.19 🟡

**主题：** AI 版应用图标与原版更易区分

**变更：**
- 图标改为青绿霓虹边框 + 六边形光晕 + 大号青橙渐变 **AI** 角标（保留纸张/图表/铅笔产品识别）
- 小尺寸（任务栏/桌面）下与原版深蓝图标一眼可辨

**关联里程碑：** M16

### 0.3.18 🟡

**主题：** 编辑画布表格高度随行数/行高正确变化

**变更：**
- 编辑态表格行改为固定行高（不再 `height:auto` 被长绑定文案撑破）
- 表格外壳 `overflow:hidden`，外框高度与可见内容一致
- 静态表 `clamp` 始终 `h = 行数×行高`；横表 SQL 改行高时按可见行数伸缩外框
- 无预览数据时，SQL 填充表按外框高度估算可见行，避免陈旧 `tableRows=30` 整表外溢

**说明：** 「SMA报警信息报表」封面右侧 `[参] {{value}}` 是叠在表上的**数据参数控件**，不是表格单元格；减行后若参数仍留在原位置，需单独删/挪参数。

### 0.1.26 📝

**主题：** 模版管理页打开速度优化

**发布日期：** 2026-07-04（开发中）

**背景：** 模版管理默认「缩略图」模式，一进页面就串行拉取全部版式 + 每份完整模版 JSON（单文件约 450–560KB，含大量 base64 图片），并一次性渲染多份微缩预览，导致打开缓慢。

**变更：**

**模版管理页（TemplateManager）：**

- **默认列表模式并记忆**：首次打开即时呈现；用户切换的视图模式记入 `localStorage`（键 `tm-view-mode`），下次沿用
- **页面 keep-alive**：`TemplateManager` 纳入 `<keep-alive>`，改用 `onActivated` 加载，切走再切回「秒显示 + 后台仅刷新有变更的模版」
- **缩略图懒渲染**：用 `IntersectionObserver` 只为进入（或接近）视口的卡片构建微缩预览重 DOM，未入视口用等高占位
- **批量拉取**：首次进入缩略图模式改用 `/templates/full` 一次拉取，替代 N 次逐个 GET；失败回退逐个并发
- **去除多余深拷贝**：网络/本地读取到的模版对象本就是新解析结果，跳过 `cloneDeepTemplate`，省一半解析与内存
- **后端摘要 sidecar**：`{id}.meta.json` 保存轻量摘要，`GET /templates` 列目录时优先读 sidecar（mtime 不早于主文件才采用），避免解析整份大模版；保存/删除时同步维护，首次列目录自动回填

**版式与页眉页脚页（LayoutPresets）：** 同因默认缩略图 + 每次 `/layout-presets/full` + 一次性渲染全部预览而变慢，套用同款优化：

- **默认列表模式并记忆**（键 `lp-view-mode`）、**页面 keep-alive + `onActivated`**
- **缩略图懒渲染**：`IntersectionObserver` 只渲染进入视口的 `LayoutPresetMiniPage`
- **会话缓存复用**：进入页面用 `ensureLayoutPresetsLoaded()` 复用内存快照，不再每次都请求 `/layout-presets/full`（增删改仍强制刷新）；与模版管理页共享同一快照，两页互相进入更快

**全局预热与缓存复用：**

- **启动后台预热**：新增 `src/lib/prefetch-core.ts`，应用启动后在浏览器空闲时（`requestIdleCallback`）错峰预取版式库快照与模板摘要，使「首次进入」这些页也直接命中缓存，而非等切到页面才开始加载；失败静默、只跑一次，由 `MainLayout` 调用
- **编辑器/向导复用版式缓存**：模板编辑器 `boot`、版式编辑器 `loadWorking`、新建模板向导改用 `ensureLayoutPresetsLoaded()`，不再每次打开都请求 `/layout-presets/full`
- **离线兜底不卡缓存**：`ensureLayoutPresetsLoaded` 在上次为离线态时自动重试联网，避免启动早期后端未就绪把内存缓存写死为空/过期

**全页体验优化（点进即用）：** 将「打开即用、无需等待」的目标推广到全部常用页：

- **签名库（SignaturesLibrary）**：原先进页即对每条签名逐个 `GET /signatures/{id}` 拉图（N+1）。新增会话缓存 `src/lib/signature-registry.ts`（摘要缓存 + 按需图片缓存 + 并发去重），页面改为 `ensureSignatureSummaries()` 取摘要、`IntersectionObserver` 只为可见行懒加载预览图；页面纳入 keep-alive + `onActivated`；增删改后统一 `invalidateSignature()`。模板编辑器签名下拉与「从库载入图像」也复用该缓存，不再重复请求
- **生成报表（ReportGenerator）**：纳入 keep-alive；一次性事件监听留在 `onMounted`，模版/连接列表刷新移至 `onActivated`，切走再回即时呈现且下拉与其它页新增项同步
- **历史报表（ReportHistory）**：原默认「缩略图」模式会一次性渲染全部 PDF。改为**默认列表并记忆**（键 `rh-view-mode`）、纳入 keep-alive + `onActivated`；缩略图模式用 `IntersectionObserver` 只挂载进入视口的 `PdfExportThumb`
- **设置页（Settings）/ 仪表盘（Dashboard）**：纳入 keep-alive，避免每次进入重复触发各子区块的初始化请求 burst
- **启动预热扩展**：`prefetch-core` 在版式库、模板摘要之外，追加错峰预热签名摘要，使签名库首次进入亦即时呈现（图片仍按需懒加载）

**说明：** 本版仅优化「打开/加载」路径，未改动模版/版式/签名数据格式；图片外置与预生成静态缩略图（更彻底的体积优化）留待后续。

**关联里程碑：** M7（体验）
