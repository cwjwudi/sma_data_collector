# 版本发布记录（CHANGELOG）

> **Report Editor** 桌面版 semver 变更的**唯一完整记录**。发版、写 `latest.json`、对外说明时以本文为准。  
> 里程碑与工单规划见 [002_里程碑与工单.md](002_里程碑与工单.md)；打包步骤见 [packaging/README.md](../packaging/README.md)。

---

## 维护说明

每次发版请：

1. 在本文**顶部「详细记录」**新增一节（最新版本在最上）。
2. 更新下方**版本一览表**的状态与日期。
3. 执行 `node packaging/scripts/bump-version.mjs <版本> --notes "..."` 同步 `frontend/package.json` 与 `packaging/updates/latest.json` 占位。
4. 打包完成后用 `generate-update-manifest.mjs` 填入 SHA256，并同步 Portal `public/downloads/report-editor/latest.json`。
5. 在 [002_里程碑与工单.md](002_里程碑与工单.md)「变更记录」追加一行摘要（可选，避免在 002 重复写全文）。

**状态图例：** ✅ 已发布 · 🟡 已打包待 Portal · 📝 开发中 / 草案

**用户数据目录（安装版）：**

| 系统 | 路径 |
|------|------|
| Windows | `%APPDATA%\sd-sma-report-editor\backend-data\` |
| macOS | `~/Library/Application Support/sd-sma-report-editor/backend-data/` |

### 0.1.13 🟡（Mac 已发布，Win 待打包）

### 0.1.12 ✅

**状态：** macOS arm64、Windows x64 均已发布（Portal）

**发布日期：** 2026-05-22

**变更：**

- **连接 Tab 错误详情（T1）**：数据库/OPC 连接 Tab 悬停显示最后一次探活/测试的错误信息与时间
- **可选定时探活（T2）**：设置 →「连接定时探活」开关（默认关）与间隔（10–3600 秒）；开启后主导航与数据源页按间隔轮询
- **导出反馈「测试写回 PLC」（T3）**：生成报表页按钮，对已绑定节点写入成功态测试值
- **写回失败可观测（T4）**：手动/自动导出后写回失败 Toast + `manualHint` / `autoStatus` 摘要
- **绑定校验按已配置项（T5）**：手动导出前仅校验已填 NodeId；不要求三节点齐全
- **配置备份加固（T6）**：设置页置顶备份说明与醒目 callout；备份含生成报表偏好
- **自动导出写回（T7）**：自动导出路径沿用 `notifyExportResultToPlc`，失败摘要写入 `autoStatus`

### 0.1.11 ✅

**状态：** macOS arm64、Windows x64 均已发布（Portal）

**发布日期：** 2026-05-22

**变更：**

- **修复 Windows 应用内升级误删用户配置**：NSIS 覆盖升级时 `${isUpdated}` 为 true 不再删除 `%APPDATA%\sd-sma-report-editor\`；`deleteAppDataOnUninstall` 改为 false

- **软件更新**：升级前确认框提示先导出配置备份；启动时清理 `%TEMP%\report-editor-updates\` 历史安装包
- **打包**：`electron-builder` 输出路径由 `../../packaging` 修正为 `../packaging`（避免误写到 `_Prj/packaging/`）
- **数据源配置**：Tab 增加连接状态灯与「· N 异常」计数（M12 小切片）
- **Windows 打包**：`build.bat` 成功不再 pause；支持 `-NoPause`

**关联里程碑：** M12-T5（部分）

### 0.1.10 ✅

**发布日期：** 2026-05-22  
**Git：** `0d2ce40`

**变更：**

- PDF 导出：失败时显示可读错误与操作建议（渲染超时、磁盘、权限、数据源等）
- 手动导出前检查模版用到的数据库 / OPC UA 连接，失败时可选择取消或继续

- 自动导出失败时全局 Toast 提示（任意页面可见），并写入绑定触发历史
- **导出结果 OPC UA 写回 PLC**：「生成报表」页可配置状态（Boolean/Int）、信息（String）、路径（String）节点；手动与自动导出完成后写入，供 PLC 读取

**后端：** `POST /opcua/write_saved/{server_id}`

**关联里程碑：** M12 小切片

**已知问题（已在 0.1.11 修复）：** Windows 应用内升级会误删 AppData 中的配置与模版。
