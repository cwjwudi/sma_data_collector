# 发版 Smoke 清单（0.1.13+）

> 每次发版前在**安装版**（非 `npm run dev`）上执行。通过后再 bump manifest、打包、同步 Portal。  
> 自动化：`npm test`（仓库根目录）须全部通过。  
> **说明：**「演示与培训」/ demo-pack 已退役（见仓库 `docs/012`）；存量仿真连接仍可测连/删除（B1）。

## 0. 通用前置

- [ ] 版本号已 bump（`frontend/package.json` = 目标版本）
- [ ] `npm test` 通过
- [ ] 使用 **Mac 或 Win 安装包**（非浏览器 dev）

## 1. 补丁 F1 — Mac「打开已安装的应用」

- [ ] 设置 → 软件更新 → 下载完成后点击「打开已安装的应用」
- [ ] 不报 `object could not be cloned`，能正常打开 Report Editor

## 5B. 0.1.27 新增能力

### 加密备份 / 导入 / 复位

- [ ] 设置 → 备份与恢复 → **导出备份文件**：下载得到 `.rebak`，用文本编辑器打开为**乱码/密文**（非明文 JSON）
- [ ] 换电脑（或复位后）→ **选择备份文件** → 「恢复配置（保留现有并补充）」成功，数据源/模版/版式/签名/审计/设置回来
- [ ] 手动改动 `.rebak` 任意字节后导入 → 提示「已损坏或被修改」并拒绝
- [ ] **快速复位** → 二次确认后清空并恢复初始状态（PDF 实体文件不删）

### 服务地址（局域网）

- [ ] 设置 → **服务地址**：显示后端「局域网访问」`http://<局域网IP>:8000`，可点击复制
- [ ] 同网段另一台电脑浏览器访问 `http://<局域网IP>:8000/health` 返回 healthy
- [ ] 原「运行环境诊断 / 自动修复」区块**已移除**

### 一键下载安装包

- [ ] 设置 → 软件更新 → **下载完整安装包（用于重装）** → 下载到「下载」文件夹并在文件管理器中定位，**不自动安装**

### 升级卡顿修复（重点）

- [ ] 从 **0.1.26 增量升级到 0.1.27**（Win 差分 / Mac dmg）后启动不白屏
- [ ] 升级后**首次**进入「模版管理」「版式与页眉页脚」列表**秒开**（不再长时间卡顿）；稍后纸张/方向标记与实际一致（后台 sidecar 回填）

### 卸载前备份

- [ ] Windows：从「设置 → 应用」卸载 → 弹出「是否备份」→ 选「是」在「文档\ReportEditor-Backup」得到 `backend-data` 副本
- [ ] macOS：卸载前已在应用内导出加密备份（拖入废纸篓不提示，属预期）
