# Report Editor AI 0.3.166

> **任务看板**：[docs/052-✅-ReportEditor数据源配置CRUD异常.md](../../../../docs/052-✅-ReportEditor数据源配置CRUD异常.md)

## 本版目标

修复数据源 OPC UA（及 DB 同类）在存在**未正常连接**配置时，新建/删除卡顿、连点保存重复、删除连打审计的问题。

## 验收标准

1. 列表中有坏链（不可达 endpoint）时，保存 / 删除操作应在约 1s 内完成交互反馈，不被全量 `test_saved` 拖到 ~8s。
2. 新建态连点「保存」只产生一条配置（`form.id` / `draft.id` 立刻回写 + busy）。
3. 连点删除同一条：只落盘一次；后端对已删 id 不再重复审计。
4. 单测：前端探活并发 + 后端 `test_opcua_crud_052` 绿。

## 非目标

- 不缩短单次 OPC 探活超时（仍约 8s）
- 不做空名称强校验 / tab 滚入视口（P2）
