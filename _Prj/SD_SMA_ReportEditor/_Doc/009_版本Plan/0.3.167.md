# Report Editor AI 0.3.167

> **任务看板**：[docs/052-✅-ReportEditor数据源配置CRUD异常.md](../../../../docs/052-✅-ReportEditor数据源配置CRUD异常.md)

## 本版目标

0.3.166 后现场仍复现：保留坏链时，删除坏链仍久挂；新建/浏览 `127.0.0.1` 好链也慢/失败。

根因：前端 `withOpcHttpSlot` 对**全部** `/opcua/*`（含配置 DELETE）共用最多 2 槽；坏链 browse/探活占满后，删除与好链请求排队。

## 验收

1. 保留 `192.168.137.1` 坏链时，删除该配置应在约 1～2s 内完成（按钮不再长时间「删除中」）。
2. 同时存在坏链时，保存并浏览 `127.0.0.1` 可达 OPC 应正常（不被坏链拖死）。
3. 单测：`opcua-http-gate` 分层分类 + `test_opcua_crud_052`（含 drop 短超时）绿。
