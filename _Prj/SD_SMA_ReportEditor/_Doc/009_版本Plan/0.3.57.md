2. **数据库配置画面空白**：已进入「数据库工作台」Tab，但主区看不到连接表单 /「+ 新建」等工作台内容（仅剩背景与 Tab 壳）。

## 初步根因（待实现时验证）

### A. 滑动锁（`DatasourceLockToggle.vue`，0.3.52 引入）

- 轨道是 `<button class="ds-lock-track">`，内部用 **百分比宽度 fill** + `left: calc(thumbPct% - 14px)` 定位拇指。
- **风险**：未强制 `appearance: none` / `box-sizing` / 固定宽高时，Electron/Chromium 默认 `button` 样式或父级 flex 可能导致轨道被撑大；百分比子元素在「父宽未钉死」时布局失控，看起来像一整块白胶囊。
- 拇指用 Emoji（🔓/🔒）在 macOS 上字号/基线不稳定，加剧视觉错乱。
- **对照**：设置页开关用 `settings-switch-track` + `transform: translateX`，结构更稳，本页应向其对齐或复用同一视觉规范。

### B. 数据库工作台空白（`DataSourceConfig.vue` + `DatabaseWorkbench.vue`）

优先排查顺序：

1. **异步挂载 / 启动遮罩** — `defineAsyncComponent` + `pageBooting` / `panelChunkLoading`；遮罩已关但子组件未露出时会出现「壳在、内容空」。
2. **竖向高度链断裂** — `page-fill-height` → `page-tab-stage` → `page-tab-body` → `.wb` → `.main`；任一层高度为 0 则主区空白透底。
3. **运行时异常** — `DatabaseWorkbench` 渲染失败时异步组件可能空白且无用户可见回退。
4. **空连接态** — 无连接时应仍见「+ 新建」与占位文案；若连骨架都没有，优先查 1–3。

## 规则（数据源页 / 自定义开关，后续版本遵守）

### R1. 自定义开关必须「钉死轨道几何」

- 轨道使用**固定 px 宽高**，禁止仅靠内容撑开。
- `button` 作轨道时必须：`appearance: none`（含 `-webkit-`）、显式 `padding: 0`、`border`、`background`、`box-sizing: border-box`。
- 拇指位置优先 `transform: translateX(...)` 或固定 px；慎用「父宽未确定时的 percentage width/left 链」。

### R2. 禁止用 Emoji 充当开关拇指

- 跨平台字号/彩色 Emoji 会导致轨道视觉崩坏；用 SVG 或纯 CSS 形状。

### R3. 与设置页开关视觉对齐

- 数据源锁可以是「滑动确认」交互，但**静置态**外观应接近 `settings-switch-track`（高度、圆角、对比度）。

### R4. 配置主区禁止「无反馈空白」

- 异步面板：加载中 → 文案/遮罩；失败 → 错误条 + 重试；成功但无数据 → 占位指引。
- 禁止遮罩消失后主区高度为 0 或完全无节点。

### R5. 全高页面必须打通高度链

- `page-fill-height` 页从 `MainLayout.content-scroll` 到最内工作区，每层 `flex` / `min-height: 0` 可预期；改布局时用数据源页回归。

### R6. 锁状态与可编辑控件绑定

- 改连接的控件统一吃 `datasourceLocked`；只读说明可见。
