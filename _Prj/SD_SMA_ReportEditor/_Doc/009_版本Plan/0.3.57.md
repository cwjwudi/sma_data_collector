## 目标

修复「数据源配置」页两大可见缺陷，并沉淀本页 UI 规则，避免滑动锁与工作台再次「看起来像坏了」。

1. **滑动锁开关 UI 错误**：右上角「可编辑 / 已锁定」轨道变形（过大白块、不像开关）。
2. **数据库配置画面空白**：已进入「数据库工作台」Tab，但主区看不到连接表单 /「+ 新建」等工作台内容（仅剩背景与 Tab 壳）。

## 现象（0.3.56）

| 区域 | 现象 |
|------|------|
| 页眉右侧 | 文案显示「可编辑」，但滑动轨道呈异常大白块，不像 88×28 胶囊轨 |
| Tab | 「数据库工作台 (0/0)」「OPC UA (0/0)」可切换 |
| 主区 | 几乎空白（紫蓝渐变底），看不到「数据库连接」表单、「+ 新建」、对象树 |
| 对照 | 设置页其它 `settings-switch` 正常；本问题集中在数据源页 |

## 初步根因（待实现时验证）

### A. 滑动锁（`DatasourceLockToggle.vue`，0.3.52 引入）

- 轨道是 `<button class="ds-lock-track">`，内部用 **百分比宽度 fill** + `left: calc(thumbPct% - 14px)` 定位拇指。
- **风险**：未强制 `appearance: none` / `box-sizing` / 固定宽高时，Electron/Chromium 默认 `button` 样式或父级 flex 可能导致轨道被撑大；百分比子元素在「父宽未钉死」时布局失控，看起来像一整块白胶囊。
- 拇指用 Emoji（🔓/🔒）在 macOS 上字号/基线不稳定，加剧视觉错乱。
- **对照**：设置页开关用 `settings-switch-track` + `transform: translateX`，结构更稳，本页应向其对齐或复用同一视觉规范。

### B. 数据库工作台空白（`DataSourceConfig.vue` + `DatabaseWorkbench.vue`）

优先排查顺序：

1. **异步挂载 / 启动遮罩**  
   - `defineAsyncComponent` + `pageBooting` / `panelChunkLoading`；`tryFinishBootForActiveTab` 依赖 `dbWorkbenchRef` 与 `connectionsLoading`。  
   - 若遮罩已关但子组件渲染失败、或 `v-show`/`dbMounted` 状态异常，会出现「壳在、内容空」。
2. **竖向高度链断裂**  
   - 依赖 `MainLayout` `.content-scroll > .page-fill-height` → `.page-tab-stage` → `.page-tab-body` → `.wb` → `.main` 的 `flex:1; min-height:0`。  
   - 任一层未吃到高度时，grid 主区可被压成可视高度≈0（渐变底透出），用户感觉「没有配置页」。
3. **运行时异常**  
   - `DatabaseWorkbench` setup / 首屏加载抛错时，异步组件可能留下空白且无 `onError`（`onError` 只覆盖 chunk 加载失败）。
4. **空连接态不可见**  
   - 无连接时应至少看到「+ 新建」与 ConnectionManager 占位文案；若连这一层都没有，更偏向 1–3，而非「只是没配库」。

1. 数据源页右上角滑动锁：轨道尺寸正常、拇指在两端、无巨大白块；「可编辑⇄已锁定」文案与状态一致。
2. 进入「数据库工作台」后，**总能看到**工作台骨架：连接 Tab 行（含「+ 新建」）+ 左侧「数据库连接」面板（表单或占位提示），不得长时间纯空白。

## 规则（数据源页 / 自定义开关，后续版本遵守）

### R1. 自定义开关必须「钉死轨道几何」

- 轨道使用**固定 px 宽高**，禁止仅靠内容撑开。
- `button` 作轨道时必须：`appearance: none`（含 `-webkit-`）、显式 `padding: 0`、`border`、`background`、`box-sizing: border-box`。
- 拇指位置优先 `transform: translateX(...)` 或固定 px；慎用「父宽未确定时的 percentage width/left 链」。

### R2. 禁止用 Emoji 充当开关拇指

- 跨平台字号/彩色 Emoji 会导致轨道视觉崩坏；用 SVG 或纯 CSS 形状。

### R3. 与设置页开关视觉对齐

- 数据源锁可以是「滑动确认」交互，但**静置态**外观应接近 `settings-switch-track`（高度、圆角、对比度），避免同一应用两种「开关」观感天差地别。

### R4. 配置主区禁止「无反馈空白」

- 异步面板：加载中 → 明确文案/遮罩；失败 → 错误条 + 重试；成功但无数据 → 占位指引（如「+ 新建」）。
- 禁止遮罩消失后主区高度为 0 或完全无节点。
- `defineAsyncComponent` 需处理 **chunk 失败** 与（尽量）**渲染失败** 的用户可见回退。

### R5. 全高页面必须打通高度链

- 使用 `page-fill-height` 的页：从 `MainLayout.content-scroll` 到最内工作区，每一层需要可预期的 `flex`/`min-height: 0`；关键布局改动时用「数据源 / 模版管理」做回归。

### R6. 锁状态与可编辑控件绑定

- 所有会改连接的控件统一吃 `datasourceLocked`（或 `locked`）；只读说明要可见（已有「数据源已锁定…」类提示，勿删）。

### R7. Plan 与发布记录分工

- 修复意图与规则写在 `009_版本Plan/<version>.md`；发版事实写入 `007_版本发布记录.md`。
