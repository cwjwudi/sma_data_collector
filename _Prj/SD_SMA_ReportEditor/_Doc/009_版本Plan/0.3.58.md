## 目标

1. **修复数据库工作台空白**（主因：`ConnectionManager` 缺少 `draft` 声明导致挂载崩溃）。
2. **滑动锁进度条与拖柄同步**。
3. **补上可拦住回归的测试**（响应同事「AI 项目 test 不行」的反馈）。

## 根因结论

1. **P0**：`ConnectionManager.vue` 使用 `draft` 但未 `reactive` 定义 → setup `immediate` watch 抛 `ReferenceError` → 子组件空白。
2. **P1**：无连接仍用三列 grid + `min-height:0`；全高页 `min-height:0` 加重「看不见」。
3. **P1**：锁 fill 用全轨 `%`，拇指用 travel `px`，两套映射。
4. **过程债**：无 Vue/布局契约测试 → 0.3.57 误判闭环。
