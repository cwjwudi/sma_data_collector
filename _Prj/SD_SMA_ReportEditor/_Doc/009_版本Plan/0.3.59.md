## 目标

修复「数据库工作台无连接时，新建连接表单一直刷新、输入被清空、光标丢失」。

## 根因（已写入看板）

1. `startLoadWatch` 每 2.5s 对空列表调用非 background 的 `reloadConnections`。
2. 空列表成功分支每次 `draftConn = null` + 常伴随 `connectionsLoading = true`。
3. `ConnectionManager` 将 `modelValue === null` 一律重置本地 `draft`。

## 范围

- [ ] 空列表重载不打断 `creatingNew` 草稿；API 返回 `[]` 后停止 loadWatch
- [ ] ConnectionManager：creatingNew 下 null→null 不重置 draft
- [ ] 回归测试（连续 reload 不清空已输入）
- [ ] bump **0.3.59**，Mac 包，文档收尾

## 不做

- 不改锁定业务语义
- 不重做连接列表数据模型

## 验收

1. `(0/0)` 编辑表单 10s+ 不被清空。
2. 无周期性 loading 闪烁。
3. 配置导入 / 连接变更仍刷新。
4. `npm test` 含回归用例。
