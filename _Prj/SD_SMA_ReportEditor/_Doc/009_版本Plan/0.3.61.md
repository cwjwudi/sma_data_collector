## 目标

模版/版式画布上**新建**控件时，属性「边框」默认 **隐藏**（`showBorder: false`），预览与导出 PDF 默认不绘制控件浅灰外框；编辑选中描边不受影响。旧模版缺字段仍按「显示」兼容。

> **非目标**：不是改设置页/数据源表单的 CSS 灰边。

## 范围

### 做

- [ ] `defaultElement` / 版式新建默认：`showBorder: false`
- [ ] 加载兼容：JSON 缺 `showBorder` → `true`（旧稿）
- [ ] 单测（新建默认 / 缺字段 / 显式 false）
- [ ] 目视：新建图片默认隐藏；旧模版外观不变
- [ ] bump **0.3.61**，打包

### 不做（本版）

- 不改应用 UI（input/button）皮肤边框
- 不改表格网格线、选中描边
- 不做「整页批量隐藏边框」工具（除非产品另拍板）

见看板「验收」。

## 规则（拟）

### R10. 新建控件默认无导出外框

- 新建非表格控件：`showBorder` 默认 `false`。
- 持久化缺字段：按 `true` 解释，保证旧模版 PDF 外观稳定。
