## 目标

1. 模版**与**版式：**新建**非表格控件 `showBorder` 默认 **隐藏**；旧稿缺字段仍按显示兼容。  
2. 模版**与**版式：提供**一键隐藏当前页/区非表格控件边框**。  
3. **表格完全不碰**。

> **强制同步**：模版与版式同版一并改。  
> **非目标**：不是改设置页/数据源表单 CSS 灰边。
