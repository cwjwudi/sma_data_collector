## 目标

模版**与**版式画布上**新建**控件时，属性「边框」默认 **隐藏**（`showBorder: false`），预览与导出 PDF 默认不绘制控件浅灰外框；编辑选中描边不受影响。旧模版/旧版式缺字段仍按「显示」兼容。

> **强制同步**：模版（`model.ts`）与版式（`layout-zone-element.ts`）默认值须**同版一并改**，不可只改一侧。  
> **非目标**：不是改设置页/数据源表单的 CSS 灰边。

## 范围

- [ ] 版式新建默认：`showBorder: false`（与模版同步）
