# 版本 Plan

本目录用于记录 **Report Editor（AI 版）每个版本** 的规划（目标、范围、验收、不做项等）。

与 [`../007_版本发布记录.md`](../007_版本发布记录.md) 的分工：

| 文档 | 用途 |
|------|------|
| **本目录各版本 md** | 发版前 / 开发中的 **计划**（要做什么） |
| `007_版本发布记录.md` | 发版后的 **事实记录**（已做成什么） |

## 文件命名

每个版本一个文件，**文件名 = 版本号**：

```text
0.3.57.md
0.3.58.md
1.0.0.md
```

不要加 `v` 前缀、不要夹空格；与 `frontend/package.json` 的 `version` 一致。

## 建议结构（可按需删改）

新建版本 plan 时可复制以下模板：

```markdown
# 0.x.y Plan

- **状态**：草稿 / 进行中 / 已发版
- **对应发布记录**：见 `007_版本发布记录.md` 中同版本条目（发版后补）

## 目标

（一句话说明本版要解决什么）

## 范围

- [ ] …

## 不做

- …

## 验收

- …

## 备注

-
```
