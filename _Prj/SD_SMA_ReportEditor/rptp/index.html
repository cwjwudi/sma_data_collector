主内容区

响应式布局：窄屏下左侧导航变为抽屉；右侧参数栏可拖拽改宽、可收起，收起后可用屏幕右侧竖条再次打开。

源码按文件夹拆分：src/html、src/css、src/ts、src/js；开发运行 npm run dev，交付 PLC 单文件执行 npm run ship 生成根目录 index.html。

建议先于模版管理在此维护可复用版式。点击表格某一整行选中后在右侧参数栏编辑纸张与页边距，并在参数栏底部保存；可视化编辑进入单独一页编排页眉/页脚区控件。新建模版时为快照套用。动态内容超高一页时，导出阶段按纸张分页（后续在「生成与导出」实现）。

当前工具参数

以下为当前工具所用参数（各菜单独立）。

全局设置不使用侧栏参数，请在中间区域调整主题后使用底部按钮保存或回退。

「关于」为说明信息，侧栏无额外参数。

模版在中栏管理；列表可新建与删除，编辑模式下从左侧拖入控件到画布，右侧编辑尺寸、颜色与文本。数据保存在浏览器本地。

请点击表格中的某一版式行以在右侧编辑纸张与页边距并保存；或点击顶栏「新建版式」。未选中行时不显示下方表单。

在此编辑当前选中的版式：纸张、页边距与页眉页脚带；供新建模版优先套用。模版保存的是快照，日后修改此处预设不会牵动已有模版。
