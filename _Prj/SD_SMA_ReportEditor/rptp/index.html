主内容区

响应式布局：窄屏下左侧导航变为抽屉；右侧参数栏可拖拽改宽、可收起，收起后可用屏幕右侧竖条再次打开。

源码按文件夹拆分：src/html、src/css、src/ts、src/js；开发运行 npm run dev，交付 PLC 单文件执行 npm run ship 生成根目录 index.html。

版式与页眉页脚

建议先于模版管理在此维护可复用版式。点击表格某一整行选中后在右侧参数栏编辑纸张与页边距，并在参数栏底部保存；可视化编辑进入单独一页编排页眉/页脚区控件。新建模版时为快照套用。封面页与末页在此不会单独建菜单：与正文版式相同，点顶栏「新建版式」，在参数栏把页面用途选为「封面」或「末页」并保存即可；之后在「模版管理 → 新建模版」里即可勾选选用对应版式。动态内容超高一页时，导出阶段按纸张分页（后续在「生成与导出」实现）。

模版管理

画布宽高随所选纸张固定；控件落在正文区内。编辑模版时可切换正文页 / 封面 / 末页分别摆放控件；页眉页脚带由各页对应版式快照决定。封面、末页的纸张与页眉页脚带不是在模版页里「新建」，须先到左侧报表配置 → 版式与页眉页脚，用「新建版式」并把页面用途设为封面或末页；再在新建模版对话框里选用（可不选用，仅用默认留白）。

当前工具参数

以下为当前工具所用参数（各菜单独立）。

全局设置不使用侧栏参数，请在中间区域调整主题后使用底部按钮保存或回退。

「关于」为说明信息，侧栏无额外参数。

模版在中栏管理；列表可新建与删除，编辑模式下从左侧拖入控件到画布，右侧编辑尺寸、颜色与文本；顶部可切换正文页 / 封面 / 末页画布。封面、末页的版式定义在「版式与页眉页脚」中新建版式并把页面用途设为封面或末页，再在新建模版时选用。数据保存在浏览器本地。

请点击表格中的某一版式行以在右侧编辑纸张与页边距并保存；或点击顶栏「新建版式」在弹出框中选择用途、纸张与方向。未选中行时不显示下方表单。

在此编辑当前选中的版式：纸张、页边距与页眉页脚带；供新建模版优先套用。模版保存的是快照，日后修改此处预设不会牵动已有模版。
