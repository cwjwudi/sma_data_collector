# ✅ 已完成：采集器可靠性三件套（DB 丢数 / 跨年分表 / 事件循环阻塞）

- **对象**：`_Prj/SD_SMA_DATA_COLLECTOR/database/data_storage.py`。TDD 全程先红后绿。
- **Bug1 失败批次静默丢数**：批次出队后 DB 插入失败只计数不回队 → 改为失败回队头保序重试；新增内存队列上限（默认 10 万条，`SD_SMA_STORAGE_MAX_QUEUE_SIZE` 可配），超限丢最旧并节流告警（`dropped_records_total` 累计，不静默）。
- **Bug2 跨年分表运行期不建表**：跨年后新年份分表未 ensure，数据被当 DB_ERROR 丢弃到重启 → 插入前发现未 ensure 即运行期补建；补建失败则回队。
- **Bug3 同步 DB 写阻塞 asyncio 事件循环**：`execute_insert*` / `record_exists` / 补建全部包进 `asyncio.to_thread` 顺序 await，写入期间事件循环仍可调度采集/心跳/Web。
- **验收**：新增 `tests/test_db_failure_requeue.py`(8)、`test_runtime_year_rollover.py`(4)、`test_storage_nonblocking_db.py`(3)；采集器套件 **104 passed**（基线 74 + 新增 30，含下列鉴权/口令用例）。
- **行为变化**：DB 宕机期回队重试成功后会补写一次 success 反馈；超限丢弃保最新弃最旧。
