## 已确认约定（2026-07-13）

### 人话展示（已确认）

审计给现场看：**操作、结果、摘要**三栏必须是明白中文。

| 不要写在主栏里 | 应写成 |
|----------------|--------|
| PUT、DELETE、POST 等 | 「保存」「删除」 |
| `template.save` 这类英文码当标题 | 「保存报表模版」 |
| `ok` / `fail` | 「成功」/「失败」 |
| 函数名、接口路径、端口 | 不进摘要 |
| 一长串编号当摘要主角 | 摘要以**名称**为主；编号放展开详情 |

说明：存盘内部仍可用英文类型键（方便程序筛选）；**界面与摘要文案必须中文**。导出给人看的列也优先中文（或中英对照，中文在前）。

#### 操作类型怎么显示

| 存盘用的类型键 | 界面显示 |
|----------------|----------|
| `template.save` | 保存报表模版 |
| `template.delete` | 删除报表模版 |
| `template.duplicate` | 复制报表模版 |
| `layout.save` | 保存版式 |
| `layout.delete` | 删除版式 |
| `layout.duplicate` | 复制版式 |

#### 摘要怎么写（示例）

| 场景 | 摘要 |
|------|------|
| 保存一次 | 保存报表模版「日报表」 |
| 15 分钟内多次保存 | 保存报表模版「日报表」（15 分钟内共 5 次） |
| 删除一个 | 删除报表模版「日报表」 |
| 批量删除 | 删除 3 个报表模版：日报表、月报表、周报表（超过 5 个名称则「…等共 N 个」） |
| 复制 | 复制报表模版「日报表」为「日报表 副本」 |
| 失败 | 保存报表模版「日报表」失败：网络中断（短句，不要堆栈） |
| 版式 | 把「报表模版」换成「版式」即可 |

展开详情可写：对象类型（报表模版 / 版式）、编号、保存次数、起止时间，以及下面的**变更明细**——同样不要出现 PUT 等词。

### 变更明细（已确认要做）

**仍然只在「保存成功」时记**，不在拖拽过程中逐笔记（否则日志会爆）。  
每次成功保存：用「磁盘上旧稿」和「本次新稿」做对比，把差异写进本条审计的展开详情。

#### 要记到什么粒度

| 要回答的问题 | 记法（中文） |
|--------------|--------------|
| 改了多少 | 摘要带数量，如「变更 3 处」；详情列出每一处 |
| 第几页 | 「第 2 页」；页眉/页脚写「页眉」「页脚」（版式） |
| 什么控件 | 控件种类中文（文本 / 表格 / 图片…）+ 控件名称或简短标识 |
| 改前 → 改后 | 每个变更字段一行：`边框：显示 → 隐藏`、`文字：「旧」→「新」` |

#### 详情里一条变更长什么样（示例）

```text
第 1 页 · 文本「标题」
  · 文字内容：「月报」→「日报」
  · 字号：14 → 18

第 2 页 · 表格「产量表」
  · 位置 X：120 → 140
```

摘要示例：

```text
保存报表模版「日报表」（变更 3 处）
保存报表模版「日报表」（15 分钟内共 5 次，累计变更 12 处）
```

#### 和 15 分钟合并怎么一起用

- 15 分钟内多次保存 → **仍是一条**审计。  
- 变更明细按「页 + 控件 + 字段」合并：  
  - 同一字段被改多次 → **改前**保留窗口内**最早**的值，**改后**用**最新**值（中间过程可省略，避免刷屏）。  
  - 不同字段 / 不同控件 → 列表里都保留。  
- 「共 N 次」与「累计变更 M 处」都更新。

#### 谁算对比

**优先后端**：保存时读出旧文件与新内容对比（人工保存、AI 保存都能覆盖）。  
前端也可先算好传详情，但不得与后端再各记一条保存。

#### 边界（避免又看不懂或撑爆）

| 规则 | 说明 |
|------|------|
| 新增控件 | 记「新增：第 x 页 · 文本「名称」」（可无改前） |
| 删除控件 | 记「删除：第 x 页 · …」（可无改后） |
| 整页增删 | 记「新增第 x 页」/「删除第 x 页」 |
| 值太长 | 改前/改后各截断（如 80 字）+「…」 |
| 一次改动极多 | 详情最多列出约 **50～100** 处，超出写「另有 N 处未列出」 |
| 不记的噪音字段 | 内部时间戳、纯缓存、无业务含义字段 |
| **永不记** | 密码、密钥、备份口令等密文 |
| 复制 / 删除整模版 | 不要求控件级对比（复制记来源名；删除记名称即可） |

### 记哪些事

**只记真正存盘的操作**，不记拖拽、选中、打开、预览、撤销。

| 界面含义 | 何时记 |
|----------|--------|
| 保存报表模版 | 点保存成功（含新建后第一次保存、应用版式后保存） |
| 删除报表模版 | 删除成功；多选删除 → **只记一条汇总** |
| 复制报表模版 | 复制成功 |
| 保存 / 删除 / 复制版式 | 同上 |

- **改名**：记成保存类，摘要写清旧名→新名，或合并进「保存」并刷新名称。  
- **配置导入**：继续用原来的「配置导入」记录，**不要**给每个模版再刷一条「保存」。  
- **列表排序拖拽**：本版不记。  
- **AI 改完并保存**：同样记「保存报表模版…」。

### 15 分钟合并（已确认）

同一模版/版式，**成功保存**若距上次成功保存不足 **15 分钟** → **不新开一行**，更新时间、「共 N 次」，并按上节**合并变更明细**。  
删除、复制各记各的。失败单独一条，不并进成功记录。

### 谁来记（已确认）

| 动作 | 谁记 |
|------|------|
| 保存（含 15 分钟合并 + 变更对比） | **后端**在保存成功后写（含 AI） |
| 删除 / 复制 | **前端**在操作成功后写（批量删除一条） |
| 禁止 | 同一次成功保存记两遍 |

### 拟改落点

1. 后端：保存成功 → 旧稿/新稿对比 → 中文摘要 + 变更明细；15 分钟内合并。  
2. 前端：删除/复制 → 中文摘要；保存不再重复记。  
3. 操作审计页：操作/结果中文；展开区用可读排版展示「页 · 控件 · 字段：旧→新」。  
4. 单测：对比函数（增删改控件/字段）、合并窗口内同一字段、截断与密文字段过滤、中文标签。

## 还建议补充的约定（建议默认 ★，可不挡开工）

主需求（中文 + 保存记明细 + 15 分钟合并）已经够用。下面是实现时容易踩坑、建议一并写死的点：

| # | 缺口 | 建议默认 ★ |
|---|------|------------|
| G11 | **哪些字段要对比、中文叫什么** | 维护一张「字段中文名表」（如边框、文字内容、字号、位置 X/Y、宽高、填充色…）。**只对比表内字段**；表外内部字段当噪音忽略，避免英文键蹦进详情 |
| G12 | **表格单元格 / 很长的 SQL** | 记「第 x 页 · 表格「名」· 单元格 (行,列)」；SQL/长文本按 80 字截断；不要整表每个空单元格都报变更 |
| G13 | **点了保存但其实没改** | 仍记一条「保存报表模版「×」」，摘要可写「无内容变更」或「变更 0 处」；详情可空 |
| G14 | **新建模版第一次保存** | 无旧稿可对比 → 记「新建并保存报表模版「×」」，详情可列「新建模版」或控件清单摘要（不必假改前） |
| G15 | **操作者显示** | 展开显示「本机用户：×× / 电脑：××」（已有 actor）；不要只丢英文键 |
| G16 | **旧审计类型中文** | 本切片**建议**把设置页里已有类型（连接保存、导出等）也映射成中文，避免一半中文一半 `db.connection_save` |
| G17 | **导出 CSV** | 「摘要」列已是中文；变更明细可放在「详情」列（多行文本或一条可读串），避免 CSV 里只有内部 JSON 键名 |
| G18 | **日志体积** | 明细变大后，仍受约 90 天 / 5000 条限制；单条详情过大时优先截断变更条数，而不是取消合并 |
| G19 | **绑定类变更** | OPC/SQL 绑定变更要记，但**值里若像口令则脱敏**（显示「（已脱敏）」） |
| G20 | **撤销后再保存** | 只对比「磁盘旧稿 ↔ 本次保存稿」，中间撤销过程不单独成条（与「只在保存时记」一致） |

- 完整模版版本库 / 一键回滚到某次保存  
- 每一次拖动、每一次属性面板按键都实时记  
- 审计上传云端  

### 计划是否够开工？

**够。** 实现时优先落地：中文展示 → 保存对比 + 明细 → 15 分钟合并 → 删/复制；G11 字段中文表与 G12 表格截断尽量同版带上，否则详情容易又出现英文键或超大 SQL。
