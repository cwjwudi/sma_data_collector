# ⌛️ 未完成：Electron 整机单实例强制

## 产品诉求

1. 同一台电脑上，**Report Editor AI 桌面版**同时只允许跑 **1 个进程/主窗口**。  
2. 用户再次双击图标 / 开第二个实例时：应**聚焦已有窗口**（或托盘恢复），而不是再开一套后端抢 8000 端口。  
3. 本轮先写看板；实现另开版本切片。

## 现状（代码对照）

| 点 | 现状 |
|----|------|
| Electron `requestSingleInstanceLock` | **未使用**（`main.cjs` 无单实例锁） |
| 后端端口 | 固定 **8000**；第二实例再拉后端易失败或行为怪异 |
| 绑定地址 | `BACKEND_BIND_HOST = '0.0.0.0'`（本机 + 局域网网卡都监听） |
| 网页版静态资源 | 安装包/有 `web` dist 时，后端挂载前端；浏览器可打开同端口 |

结论：桌面端**目前不强制单开**；第二实例风险主要在端口与数据目录并发。

## 建议实现（默认）

| 项 | 约定 |
|----|------|
| API | Electron `app.requestSingleInstanceLock()`；未拿到锁 → `app.quit()` |
| 第二实例 | `second-instance` → 显示并 `focus` 已有 `mainWindow`（若最小化则还原） |
| 范围 | **仅约束 Electron 桌面进程**；不禁止本机浏览器打开网页版（见下） |
| 平台 | Windows / macOS 均做 |
| 验收 | 连开两次安装版 → 只有一个窗口；第二次把第一个拉到前台 |

# 说明：用别的浏览器访问，能不能正常操作？

## 短结论

| 场景 | 能否用 | 说明 |
|------|--------|------|
| **本机浏览器**打开 `http://127.0.0.1:8000/`（桌面版已启动且已挂静态页） | **大部分可以** | 与 Electron 共用同一后端与数据目录 |
| **同网段其它电脑浏览器**打开 `http://<工控机IP>:8000/` | **页面多半能开**，部分能力受限 | 后端默认绑 `0.0.0.0`；防火墙需放行 8000 |
| **仅开浏览器、不启动桌面版** | 安装版通常**不行** | 后端一般由 Electron 拉起；无进程则无服务 |
| **开发** `npm run dev`（Vite :5173）+ 本机 uvicorn | 可以 | 纯 Web 开发路径，与安装包行为略有差异（无部分 IPC） |

## 架构示意

```text
                    ┌─────────────────────────┐
  本机 Electron ────┤  同一 FastAPI :8000      │
  本机 Chrome ──────┤  数据目录共用            │
  局域网浏览器 ─────┤  静态页 + /api/*         │
                    └─────────────────────────┘
```

桌面单实例锁**只挡第二个 Electron**，**挡不住**浏览器再开多个标签——标签都打到同一后端。

## 功能限制对照（浏览器 vs Electron）

| 能力 | Electron | 本机浏览器 | 局域网浏览器 |
|------|----------|------------|--------------|
| 模版/版式编辑、列表、保存 | ✅ | ✅（走 HTTP API） | ✅（同左，视防火墙） |
| 数据源配置、测连、探活设置 | ✅ | ✅ | ✅ |
| 报表生成 / PDF 导出 | ✅（可走隐藏窗等优化） | 基本可用；部分桌面专用 IPC 可能弱化 | 同左 |
| 选文件夹 / 部分系统对话框 | ✅ 原生对话框 | 受浏览器安全限制（或降级） | 同左 |
| 应用内 **AI 聊天** `/settings/ai/chat*` | ✅ | ✅（loopback） | ❌ **403 仅本机** |
| AI Pending 确认、工具目录等 | ✅ | ✅（loopback） | ❌ **403 仅本机** |
| Agent `/v1/*`（Cursor 等） | 本机免 Token；局域网需 Token +「允许局域网访问 Agent API」 | 同左 | 需开关 + Token |
| 自动更新 / 托盘 / 单实例 | ✅ 仅桌面 | — | — |
| 文件协议、部分本地路径 | ✅ | 受限 | 受限 |

> **安全提示**：`0.0.0.0` 意味着局域网能打到 Web UI 与多数业务 API。现场若只需本机用，应靠防火墙关 8000，或后续做成「仅 127.0.0.1 绑定」配置项（本看板可列为二期）。

## 与「整机只能开一个软件」的关系

| 需求理解 | 单实例锁能否覆盖 |
|----------|------------------|
| 不能开两个 **桌面窗口** | ✅ 本切片默认目标 |
| 不能同时 **桌面 + 浏览器** 操作 | ❌ 需额外「互斥会话」或关网页版挂载 |
| 局域网别人不能打开 | ❌ 属网络绑定 / 防火墙 / 鉴权，另案 |

**默认产品解读**：强制 **一个 Electron**；浏览器访问作为运维/应急入口保留，并在文档中写清限制（尤其 AI 本机限定）。
