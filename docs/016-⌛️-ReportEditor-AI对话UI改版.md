用户希望把 ReportEditor **AI 助手对话 UI**改成接近参考图的体验：深色玻璃态（glassmorphism）、居中对话主区、顶栏模型选择、右对齐用户气泡 + 头像、左对齐助手正文（无厚气泡）、底栏大圆角输入区。

## 参考稿要素摘录（实现时对照）

| 区域 | 观感 |
|------|------|
| 整体 | 深色半透明面板 + `backdrop-filter` 模糊；大圆角；细浅描边 |
| 顶栏 | 左：模型下拉（图标 + 名称 + chevron）；右：分享 / 新对话 / 布局类图标 |
| 用户消息 | 右对齐深色圆角气泡；右侧圆形头像（缩写） |
| 助手消息 | 左对齐；Agent 名胶囊标签；正文**无**厚底气泡，Markdown 标题/列表清晰 |
| 助手操作 | 文末小图标：复制 / 赞 / 踩 / 收藏（本产品可裁剪） |
| 输入区 | 底部大圆角输入框；内嵌底栏：附件类按钮（左）+ 发送（右，高亮色） |
| 侧栏 | 窄条历史/分页（参考「1 of 31」）；本产品是否引入会话列表待拍板 |

## 与现状差距（粗对照）

| 点 | 现状（AiDrawer） | 参考稿 |
|----|------------------|--------|
| 形态 | 右侧抽屉 + 右下 FAB | 大面积居中玻璃主区（可仍为抽屉内全高） |
| 主题 | 偏应用浅色/现有 token | 深色玻璃态 |
| 气泡 | 用户/助手均气泡感较强 | 用户有气泡；助手贴底透明 |
| 顶栏 | 标题/关闭/调宽等 | 模型选择 + 新对话等 |
| 输入 | composer + 排队收纳条 | 大圆角一体输入 + 底栏动作 |
