# ⌛️ 未完成：多选尽量展示共有项；需要时才统一改绑定

## 产品诉求（用户原话要点 · 2026-07-14）

1. **很多字段都可以显示**——不必只限 B3 那一小撮「外观」。  
2. 选中项里**如果已经有绑定**，多选面板也要能看到，并在**需要时**统一修改（改 NodeId / 绑定方式 / 显示格式等）。  
3. 理由：现场大量控件的绑定动作是**重复劳动**，逐个点开单选太慢。  
4. **纠正（同日）**：不是「一多选就把已有绑定强制改成同一个值」。各控件原有绑定必须保持，直到用户**主动**提交批改。

## 硬性交互（必须遵守）

| 规则 | 说明 |
|------|------|
| **只读展示，默认不写** | 多选 / 切换选区 / 打开共有面板 → **不得**改写任何选中项字段 |
| **值不一致 →「混合」** | 绑定方式、NodeId、小数位等不一致时显示混合态，**各控件仍保留各自原值** |
| **仅用户操作才写回** | 点选分段、失焦提交、点选 OPC 节点并确认等**明确操作**后，才把该字段写成同一新值 |
| **可统一 ≠ 会统一** | 「允许统一改」是能力；「一选中就统一」是禁止行为 |

## 拟展示分组

### A. 已有 · 外观（保持）

`showBorder` · `bgColor` · `color` · `fontSize` · `fontFamily` · `textAutoWrap` · `alignX` · `alignY`

### B. 显示格式

| 字段 | 说明 |
|------|------|
| `decimalPlaces` | 小数位数（REAL） |
| `nullDisplayMode` | 空值：空白 / 「空值」 / 默认文字 |
| `dateFormat` | 仅全为 date 时 |

### C. 绑定（同类型才出整区 · Q4=B）

| 字段 | 说明 |
|------|------|
| `bindingKind` | 无 / OPC UA /（同类型均支持时再出 SQL·Mongo） |
| `opcuaNodeId` | OPC 节点；混合显示「混合」，**确认后**全集同值 |
| `sqlText` / 可视化 SQL 摘要 | 仅同类型且均支持 SQL |
| `mongoQuery` 关键字段 | 仅同类型且均支持 Mongo |

**交互约定：**

1. 选中 ≥2 且**类型完全一致**且能绑定 → 出「绑定」区（只展示，不写）。异类型 → 整区隐藏 + 提示选同类型。  
2. 值不一致 → 「混合」，**原值不变**。  
3. 仅用户确认操作后 → 才把该字段写成同一新值。  
4. 无绑定的项也可在用户主动操作后一并设成同一绑定。  
5. 改 `bindingKind`（Q3=A）：**只改 kind**，不清空 NodeId/SQL。  
6. OPC 点选：picker **确认**后写回全集。  

### D. 仍不做（本条）

| 类别 | 原因 |
|------|------|
| 几何 `x/y/w/h` | 已有对齐/组拖 |
| `zIndex` | 误改层序 |
| 图片源/旋转/配文、签名库、图表类型、页码模式 | 二期按需 |
| **表格**（整表/单元格/SQL 填充） | 另开看板 |
| 任意密码/密文 | 保持不进批改 |

### E. 文案 `text`（Q2=B）

- 普通标题文字与空值回退文案：均可批；混合不写，确认后统一。
