# ⌛️ 未完成：历史报表操作支持复制到 U 盘 + U 盘分屏模式

## 产品诉求（用户原话要点）

1. 在**历史报表**的操作里支持**一键复制到 U 盘**。  
2. 可以把**整个文件夹**复制；也可以做**单个文件夹**复制。  
3. **最好**可以打开 **U 盘模式**：左右分屏两个列表。

## 现状锚点

| 项 | 现状 |
|----|------|
| 历史报表 | 绑定导出根；单层进子目录；PDF：打开 / 所在位置 / 删除；文件夹：进入 |
| 复制到 U 盘 | **无** |
| 可移动磁盘枚举 | **无**专用 UI / IPC |
| 运行面 | 已有「仅桌面」提示；复制依赖本机文件系统 + Electron |

## 拟能力拆分

### A. 一键复制（列表操作）

| 操作 | 说明 |
|------|------|
| 复制当前文件夹到 U 盘 | 把**当前面包屑所在目录**整树拷到所选 U 盘目标 |
| 复制单个子文件夹 | 行内操作：对该 `kind=dir` 整树递归复制 |
| （可选）复制单个 PDF | 行内：单文件拷到 U 盘；建议一并做，避免只能拷夹不能拷文件 |

目标盘：优先「已识别的可移动卷」；若检测不到则退化为「选择目标文件夹…」。

### B. U 盘模式（左右分屏 · 用户点名「最好」）

| 侧 | 内容 |
|----|------|
| **左** | 现有历史报表本层列表（导出监视根，行为对齐 010） |
| **右** | U 盘（或所选可移动卷）本层列表：进目录、上级、面包屑 |
| 交互 | 左 → 右：选中项「复制到右侧当前目录」；整夹递归；进度与失败摘要 |

入口建议：历史报表顶栏开关「U 盘模式」；关闭后回到单栏。
