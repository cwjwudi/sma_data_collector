# ⌛️ 未完成：分屏「导出目录 → 目标目录」复制

## 产品诉求（累计）

1. 历史报表支持把文件/文件夹拷到外部目标。  
2. 可整夹、可单夹、可多选后批量拷。  
3. **分屏模式**：左 = 导出监视目录；右 = **任意可达目标目录**（不限 U 盘根）。  
4. 插入 U 盘 / 可移动存储时可**提示**；可快捷切到该卷，但不强制右侧只能是 U 盘。  
5. 顶栏一排按钮：把**当前选中**（含多选）拷到**右侧当前路径**。  
6. **远期**：目标可扩展为 FTP / WebDAV 等（首版不做协议实现，接口形状预留）。

## 已拍板

| # | 结论 |

## 分屏布局（已确认）

```
┌─────────────────────────────────────────────────────────┐
│ 顶栏：进入/退出分屏 │ 选目标… │ 可移动盘快捷 │ 【复制到右侧】… │
├──────────────────────────┬──────────────────────────────┤
│ 左：导出目录（监视根）    │ 右：目标目录（任意本机路径）   │
│ 面包屑 / 本层列表 / 分页  │ 面包屑 / 本层列表 / 分页       │
│ 多选 PDF / 文件夹         │ 浏览为主（首版写策略见下题）   │
└──────────────────────────┴──────────────────────────────┘
```

- 左：行为对齐 010（单层进入、分页）。  
- 右：同样单层浏览；cwd 即复制落点。  
- 主操作：**顶栏「复制到右侧」**（基于左侧选中集）。
