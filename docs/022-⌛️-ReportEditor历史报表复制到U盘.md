# ⌛️ 未完成：分屏「导出目录 ⇄ 目标目录」双向复制

## 产品诉求（累计）

1. 历史报表支持与外部目录**互相拷贝**。  
2. 可整夹、可单夹、可多选后批量拷。  
3. **分屏**：左 = 导出监视目录；右 = **任意可达目标目录**。  
4. 插入可移动盘可提示并快捷打开到右侧。  
5. 顶栏按钮：把**当前侧选中**拷到**对侧当前路径**（双向）。  
6. 远期：FTP / WebDAV 等（首版只预留接口）。

## 分屏布局（已确认）

```
┌──────────────────────────────────────────────────────────────────┐
│ 顶栏：分屏开关 │ 选右侧路径… │ 可移动盘快捷 │ 【→ 复制到右侧】【← 复制到左侧】 │
├────────────────────────────┬─────────────────────────────────────┤
│ 左：导出目录（监视根）      │ 右：目标目录（任意本机路径）            │
│ 多选 · 面包屑 · 本层分页    │ 多选 · 面包屑 · 本层分页              │
└────────────────────────────┴─────────────────────────────────────┘
```

- 「复制到右侧」：以**左侧选中**为源 → 写入**右侧 cwd**。  
- 「复制到左侧」：以**右侧选中**为源 → 写入**左侧 cwd**（仍不得逃出监视根之外的非法路径；落在左栏当前子目录）。  
- 左栏根仍为导出监视根（010）；右栏根为用户所选目标根。
