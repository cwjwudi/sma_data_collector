## Q13 附：如何判断「可移动 / U 盘」（需技术选型，建议默认如下）

| 平台 | 建议做法（首版） |
|------|------------------|
| **Windows** | 枚举盘符；`GetDriveType` == `DRIVE_REMOVABLE`（或等价 Node/系统 API）视为可移动。外置 HDD 若被标为 Fixed 则**不会**进「U 盘提示」，仍可用「选右侧路径…」打开 |
| **macOS** | 扫描 `/Volumes/*`，排除系统卷（如 Macintosh HD）；可辅以 `diskutil info` 看 `Removable`/`External`。无法 100% 区分「U 盘 vs 移动硬盘」时，统一称「可移动卷」并走**确认打开** |
| **插拔** | 轮询（如 2–3s）或系统事件；拔出时若右侧 cwd 落在该卷上 → 提示并停用拷/移直至重选路径 |

**产品文案**：界面用「可移动存储」而非硬叫「U 盘」，避免误检；确认框示例：「检测到可移动卷 `E:`，是否在右侧打开？」

> 若你要求「仅真正的 USB 闪存、排除移动硬盘」，Win/mac 都更难且易误判——**不建议首版强区分**；用确认框兜底即可。
