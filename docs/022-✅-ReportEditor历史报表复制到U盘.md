# ✅ 已完成：分屏「导出目录 ⇄ 目标目录」双向复制与移动

## 产品诉求（累计）

1. 分屏左右与外部目录**互相复制**，并支持**直接移动**。  
2. 可整夹、单夹、多选批量。  
3. 左 = 导出监视目录；右 = **任意本机可达路径**（顶栏「选路径…」人工选择，不限 U 盘）。  
4. 检测到可移动盘时**提示**；若判定为 U 盘/可移动存储，**须用户确认**后再在右侧打开该路径。  
5. **仅分屏**下提供拷/移；单栏不提供复制入口。  
6. 远期 FTP/WebDAV（首版只预留接口）。
