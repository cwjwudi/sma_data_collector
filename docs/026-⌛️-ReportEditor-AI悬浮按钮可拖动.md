# ⌛️ 未完成：AI 助手悬浮按钮可拖到任意位置并记忆

## 产品诉求

1. 右下角 **AI** 悬浮按钮常挡住分页、底栏操作、表格把手等。  
2. 需要**可拖动**挪开；松手后位置应**记住**（刷新/重开仍在）。  
3. 拖完仍能**单击打开**助手（拖动与点击要区分，避免拖一下误开抽屉）。

## 现状

- `AiDrawer.vue` 中 `button.ai-fab` 固定 `right` / `bottom`，`@click="openDrawer"`。  
- 无拖动手势、无位置持久化。

## 拟拍板

| # | 问题 | 推荐 ★ |
|---|------|--------|
| **Q1** | 拖动范围 | **A★**：视口内任意位置（边缘留 ≥8px 安全距） / **B**：仅贴四边磁吸 |
| **Q2** | 位置记忆 | **A★**：`localStorage`（本机每浏览器/壳一份） / **B**：写入服务端 prefs |
| **Q3** | 拖 vs 点 | **A★**：位移超过阈值（如 5px）算拖、不打开；未过阈值算点击打开 |
| **Q4** | 重置 | **A★**：设置页或长按 FAB「恢复默认右下角」 / **B**：首版不做重置 |
| **Q5** | 抽屉打开时 | **A★**：FAB 本来就隐藏（现状 `v-if="!open"`），拖动只作用于关闭态 / **B**：抽屉打开时另显拖动手柄 |
| **Q6** | 本条不做 | 抽屉面板整体拖动到任意角；改默认落点为左下（用拖动即可） |

## 实现范围（开工后 · 草案）

1. FAB：`pointerdown/move/up`（兼 touch）；用 `left/top` 或 `transform` 定位，窗口 `resize` 时钳回可视区。  
2. 持久化键如 `report-editor-ai-fab-pos`：`{ x, y }` 或 `{ right, bottom }`。  
3. 点击阈值区分；`user-events: none` 勿挡拖。  
4. 单测：阈值判定纯函数 + 钳制函数；手测多页遮挡。  
5. 文档与版本号。

## 验收（草案）

- [ ] 可拖离右下角，不再挡底部分页/按钮  
- [ ] 刷新后位置仍在；窗口缩小后不掉出屏幕  
- [ ] 轻点仍打开抽屉；拖动松手不误开  
- [ ] AI 关闭时 FAB 隐藏逻辑不变  

## 不做（本条登记）

- 不改抽屉宽度/位置体系（既有 expanded/resize）  
- 不强制改默认初始位置（仍默认右下，可拖走）  
- 拍板阶段不改产品代码
