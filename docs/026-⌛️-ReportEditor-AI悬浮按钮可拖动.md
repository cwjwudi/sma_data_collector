# ⌛️ 未完成：AI 按钮与展开态对话窗可拖并记忆

## 产品诉求

1. 右下角 **AI** 悬浮按钮常挡住分页、底栏操作、表格把手等 → 可拖走。  
2. **展开后的 AI 对话窗**也会挡内容 → 可拖标题栏挪开。  
3. 松手后位置**记住**；FAB 拖与点要区分，避免误开。  
4. 打开后仍能看清背后页面；误点外面不要关窗。

## 现状

- FAB：`position:fixed; right/bottom`，`@click` 打开。  
- 抽屉：右侧固定侧栏（可调宽）/ 近全屏展开；标题栏不可拖移整窗。  
- 遮罩：`backdrop-filter: blur`，点空白关闭。

### 位置记忆（约定）

| 键 | 内容 |
|----|------|
| `report-editor-ai-fab-pos` | FAB `{ left, top }`（或等价） |
| `report-editor-ai-drawer-pos` | **展开态**对话窗 `{ left, top }`；与现有宽度 / 展开尺寸存储并存 |

窗口 `resize` 时两者均钳回可视区。

## 实现范围（开工后）

1. 纯函数：`clampFloatingPos` / `isDragNotClick` + vitest。  
2. FAB：pointer 拖动 + localStorage；点击阈值。  
3. 抽屉：**仅 `expanded`** 时标题栏可拖移整窗；侧栏态布局不变（贴右 + 左边调宽）。  
4. 遮罩：去 blur → 浅灰半透明；去掉 `@click.self` 关闭。  
5. 设置页重置：清上述两键并回到默认右下。  
6. 文档与版本号（预计 **0.3.103**）。
