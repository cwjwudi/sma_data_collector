# ⌛️ 未完成：AI 按钮与对话窗可拖到任意位置并记忆

## 产品诉求

1. 右下角 **AI** 悬浮按钮常挡住分页、底栏操作、表格把手等 → 可拖走。  
2. **打开后的 AI 对话页面**也会挡内容 → **同样可拖动**挪开。  
3. 松手后位置**记住**；FAB 拖与点要区分，避免误开。

## 现状

- FAB：`position:fixed; right/bottom`，`@click` 打开。  
- 抽屉：右侧固定面板（可调宽 / 近全屏展开），标题栏不可拖移整窗。

## 已拍板（2026-07-17）

| # | 结论 |
|---|------|
| **Q1** | **A**：视口内任意拖，边缘 ≥8px 安全距（不做四边磁吸） |
| **Q2** | **A**：`localStorage` 本机记忆（不写服务端 prefs） |
| **Q3** | **A**：FAB 位移 >5px 算拖、不打开；未过阈值算点击打开 |
| **Q4** | **A**：设置 → AI 助手增加「恢复 AI 按钮/对话窗默认位置」 |
| **Q5** | **对话打开后也可拖**：拖**标题栏**（`ai-drawer__head`）移动整窗；关闭态仍拖 FAB。近全屏「展开」模式下**不拖移**（只保留收起/关闭），收起为侧栏后可再拖 |
| **Q6** | 默认落点仍右下；不改为默认左下 |

### 位置记忆（约定）

| 键 | 内容 |
|----|------|
| `report-editor-ai-fab-pos` | FAB `{ left, top }`（或等价） |
| `report-editor-ai-drawer-pos` | 对话窗 `{ left, top }`（侧栏态）；与现有宽度存储并存 |

窗口 `resize` 时两者均钳回可视区。

## 实现范围（开工后）

1. 纯函数：`clampFloatingPos` / `isDragNotClick` + vitest。  
2. FAB：pointer 拖动 + localStorage；点击阈值。  
3. 抽屉：标题栏 pointer 拖动（避开模型下拉/图标按钮）；侧栏态用 `left/top`（或 transform）定位；**保留**左边调宽 grip 与「展开」。  
4. 设置页重置：清上述两键并回到默认右下。  
5. 文档与版本号。

## 验收（草案）
