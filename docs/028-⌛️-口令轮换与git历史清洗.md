# ⌛️ 未完成：泄露口令失效 + 仓库历史去密

## 背景

历史口令（如曾出现的 `Br54644800@`）不仅在 git 历史中，且曾内置于已分发的 ReportEditor 0.3.x 安装包；演示库还有过公网 cpolar 隧道入口。A 档已完成工作区脱敏与环境变量注入，**不能替代**现场改口令与历史清洗。

## 主线 1 · 口令轮换（高优先 🏭）

| 步骤 | 动作 | 验收 |
|------|------|------|
| 1 | 凡用过泄露口令的库（演示 / 生产相关）**改口令** | 旧口令无法登录 |
| 2 | 各服务用 `SD_SMA_DB_PASSWORD`（及同类注入）指向新口令；配置文件不回写明文 | 服务能连库；仓库/配置无新明文 |
| 3 | 关掉或收紧演示库公网隧道；旧 0.3.x 安装包视为已泄密，升级到当前版本 | 外网不可再直连演示库 |
| 4 | 在本看板记录：日期、机台、库名/实例（勿写新口令明文） | 可审计「已轮换」 |

## 主线 2 · git 历史清洗（需协调 🏭）

| 步骤 | 动作 | 验收 |
|------|------|------|
| 1 | Gitea 备份；约定维护窗口；通知所有协作者 | 书面/群确认 |
| 2 | 用 `git filter-repo` 或 BFG 清除历史中的口令串与误提交大 blob（如 Obsidian 插件） | 本地清洗分支自检通过 |
| 3 | force push 至 `origin`；各克隆重拉或硬重置 | 远端历史无旧口令；协作方同步完成 |
| 4 | `git log -S` / 全历史检索确认 | 旧口令不再出现在可达历史中 |

> **本机/Agent 默认不执行 force push**。需要操作手册时，用户明确说「出清洗手册」后再提供命令清单。
