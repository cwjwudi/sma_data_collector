### ✅ D6 · 表格内边距 / 行高 / 字号模型不同（`retest-0.3.127` → **0.3.128**）

- **装包 `0.3.127` 复验**（`retest-0.3.127-09-28-27`）：列宽/行高已接近；用户仍感「表格完全不一样」，根因两处：  
  1. **外套框**：矢量在控件外框再描一圈表线，内网格缩进 4px shell → 出现「相框式」双线；Mini 是透明 padding + 仅内网格。  
  2. **表字号**：正文表误用控件字号 `×0.8`（且受 `min(11px, minRowH×0.55)` 挤压）；Mini 节点用**原字号**，td 为 `max(10px, 0.85em)`（字号 12 → **10.2px / 7.65pt**）。  
- **处理（0.3.128）**：外框改画在内网格；字号/行高度量统一为 `max(10, fontSize×0.85)`。zone 表不加 shell（不变）。  
- **验收**：单测 `body table cell font uses max(10px, 0.85×…)`；五档 `retest-0.3.128-09-42-00`：外套框消失（顶线 y/x 仅内网格 `259.5/66.8`，旧双线 `256.5/63.8`）；`pressure` 宽 27.04≈朱雀 7.65pt（旧 25.45≈7.2pt）。
