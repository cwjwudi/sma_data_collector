# 📋 差异清单（待修）

> 勾选规则：代码落地 + 同戳五档复验（至少档 1 vs 档 2）后再标 ✅。

## P0 · 语义/强可见（建议先做）

### ⌛️ D1 · 页/带背景色不一致

- **现象**：预览稳正文带 `#f9f9fb`、眉脚淡紫底；矢量近白，另画内容区淡框。参数/Logo 白底在灰底上「浮起」，矢量上看不到卡片感。  
- **落点**：Mini `.mini-body` / `.mini-band`；layout-v2 无 fill。  
- **方向**：要么矢量按同一 token 填色；要么（与 035 待做一致）把页背景做成**可编辑**后两边同读。  
- **验收**：封面/正文/封尾底色观感一致（或产品明确「矢量永远白纸」并改预览导出）。

### ⌛️ D2 · 参数白底卡片在矢量上「消失」

- **现象**：冒烟参数 `bgColor=#ffffff` + 预览灰底 → 白卡片；矢量白纸 + 同白底 → 无卡片轮廓（`showBorder=false` 两边都不描边）。  
- **落点**：模板数据 × D1；非单纯 align bug。  
- **方向**：优先 D1；或矢量在 `bgColor===pageBg` 时可选淡边（需产品拍板）。  
- **验收**：正文五参数在档 1/2 都能看出独立内容块（或明确取消卡片语义）。

### ⌛️ D3 · 日期控件未按 `dateFormat` 渲染

- **现象**：正文眉 `date`（`yyyy-MM-dd HH:mm`）预览稳有导出时刻；矢量缺该行。  
- **落点**：Mini `formatTplDate` → `formatLayoutDate`；layout-v2 仅 `bound \|\| el.text`，不格式化「现在」。  
- **验收**：档 1 眉右出现与档 2 同格式的时间（允许数秒误差）。

### ⌛️ D4 · 页码模式未实现（`slashTotal` / `circle` / `cnPage`）

- **现象**：脚 `pageNumberMode=slashTotal` → 档 2 为 `2/3`，档 1 为 `2`；圆形框未画。  
- **落点**：`formatPageNumberDisplay`（layout-zone-element）；v2 `pageLabel = String(pageCount)` 仅当前页。  
- **验收**：三种模式在 zone/正文页码与预览一致；总页数正确。

### ⌛️ D5 · 文本截断 / 不换行度量不一致

- **现象**：标题缺 `）`；眉左 `Smoke`→`Smo`；脚注更短。控件多为 `textAutoWrap=false`。  
- **落点**：字号 0.8×（D7）、字体度量、inset（v2 `+2/-4`）、`drawWrappedInBox` 裁切。  
- **验收**：同文案在档 1/2 完整可见，或两边同等省略规则（含 `…`）。

## P1 · 版式度量（表/字号/对齐微调）

### ⌛️ D6 · 表格内边距 / 行高 / 字号模型不同

- **现象**：表内字偏上或偏紧；列对齐「差不多但不贴」。  
- **落点**：Mini 外壳 pad 4px、td `3×5`、`line-height:1.3`、内容感知行高；v2 等分行高、`rowH*0.55`、忽略正文表 `el.fontSize`。  
- **验收**：横表/纵表字在格内垂直大致居中；列中线与档 2 偏差可接受（建议 |Δmid|<4pt）。

### ⌛️ D7 · 正文控件字号缩放（×0.8）未对齐

- **现象**：预览正文 `fontSize * 0.8`；矢量用原字号 → 占位与截断连锁（喂 D5）。  
- **落点**：`TemplateMiniPage.miniTplElStyle`；layout-v2 `Math.max(7, el.fontSize)`。  
- **方向**：矢量跟 Mini 同系数，**或**取消 Mini 0.8（改预览，影响面更大）。  
- **验收**：正文标题/参数字号目视同级。

### ⌛️ D8 · 封面眉表字位微调

- **现象**：「批次报告」等相对右缘仍有数 pt～十余 pt 偏差。  
- **落点**：zone 表 pad、字宽、右对齐实现。  
- **验收**：封面四行标签/值与档 2 锚定 Δx 收敛（建议 <6pt）。

### ⌛️ D9 · 列/格背景色

- **现象**：预览可 per-col / per-cell 背景；矢量只填整表 `bgColor`。  
- **验收**：设置了列/格底色的模板在档 1 可见对应色块。

### ⌛️ D10 · `showBorder` 语义边界

- **现象**：Mini：`showBorder === false` 才隐藏，否则淡边；v2：仅 `showBorder` 为真才画边。`undefined` 历史数据可能不一致。  
- **验收**：hydrate 后两边同隐同显；单测覆盖 `undefined/false/true`。
