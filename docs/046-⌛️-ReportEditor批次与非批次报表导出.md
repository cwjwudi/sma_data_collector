# ✅ 已完成：产品口径登记

## 区分两种报表生成

| 类型 | 与批号关系 | 落盘规则 |
|------|------------|----------|
| **批次报表** | 跟批号走（**现网默认行为**） | 在大文件夹下建以**批次号命名**的子文件夹，本批次全部报表文件放该子文件夹内 |
| **非批次报表** | **与批号无关** | 在模版上**单独指定目标文件夹**（本机绝对路径）；触发生成后，文件直接写入该指定文件夹（不再按批号建子目录） |

## 要点

- 批次报表：保持当前导出方式，不改语义。  
- 非批次报表：目标路径是**模版侧**配置项，不是全局导出根下的批号子目录。  
- 触发生成后两类路径行为必须明确可区分、可验收。

# ✅ 已完成：Q1–Q6 产品拍板（2026-08-08）

| # | 结论 | 口径 |
|---|------|------|
| **Q1** | **A** | 「批次 / 非批次」类型**只挂模版**；模版定了就全局按这种落盘（绑定不覆盖、不另挂类型） |
| **Q2** | **A** | 非批次「目标文件夹」**只允许本机绝对路径**（如 `D:\Reports\Daily`）；非法/不存在 → **显式失败**，禁止 silently 落到批号目录 |
| **Q3** | **A** | 非批次产出**进历史报表 + 写审计**（与批次一样能看、能拷 U 盘） |
| **Q4** | **A** | 手动「导出 PDF」**也按类型走**（批次建批号目录 / 非批次去模版指定目录） |
| **Q5** | **A** | 手动导出且类型=批次、但当前无批号 → **报错，禁止导出**（不弹窗填批号、不回落全局根） |
| **Q6** | **A** | 非批次文件名规则与现网批次相同（模版名 + 时间戳等），**只是目录不同**；本期不单独配文件名模板 |

### 配置落点（实现用）

- **模版字段**（名称待定，语义固定）：
  1. `reportKind`：`batch` | `nonBatch`（或等价中文枚举）
  2. `nonBatchOutputDir`：本机绝对路径；仅当 `reportKind=nonBatch` 时必填且校验
- **自动结批绑定**：不增加类型字段；沿用所绑模版的类型与目标目录。
- **历史扫描**：须覆盖非批次绝对路径产出（与现有批号子目录一并可见/可拷）。

## 拟改方向（待实现）

1. **模版模型 + UI**：增加类型开关；非批次时露出「目标文件夹」绝对路径输入（可选手改；校验存在且为目录）。  
2. **导出调度**（自动结批 + 手动导出共用）：
   - `batch` → `全局导出根/<批号>/`；无批号 → **失败**（可读错误）。  
   - `nonBatch` → `模版.nonBatchOutputDir/`；路径缺失/非法 → **失败**，禁止落到批号目录。  
3. **历史报表 + 审计**：非批次落盘后与批次同等登记；历史分屏能扫到对应绝对路径下的文件；U 盘拷移沿用现网。  
4. **文件名**：复用现网批次命名逻辑，不另开模板。  
5. **单测 / 手测**：两种类型各触发一次（自动 + 手动）；无批号手动批次导出须失败；核对路径、文件名、历史可见、审计有记录。

## 验收（实现后）

- [ ] 批次报表：仍落到 `大文件夹/<批号>/`，本批多文件同目录。  
- [ ] 非批次报表：落到模版指定绝对路径文件夹，目录名与批号无关。  
- [ ] 两类互不串路径；配置缺失/路径非法时报错可读。  
- [ ] 手动导出遵守同一套类型规则；批次且无批号 → 禁止导出。  
- [ ] 非批次产出出现在历史报表分屏，且有审计；可拷 U 盘。  
- [ ] 非批次文件名与批次同规则（仅目录不同）。
