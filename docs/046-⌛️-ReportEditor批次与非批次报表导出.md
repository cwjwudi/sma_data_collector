# ✅ 已完成：产品口径登记

## 区分两种报表生成

| 类型 | 与批号关系 | 落盘规则 |
|------|------------|----------|
| **批次报表** | 跟批号走（**现网默认行为**） | 在大文件夹下建以**批次号命名**的子文件夹，本批次全部报表文件放该子文件夹内 |
| **非批次报表** | **与批号无关** | 在绑定配置里**单独指定目标文件夹**；触发生成后，文件直接写入该指定文件夹（不再按批号建子目录） |

## 要点

- 批次报表：保持当前导出方式，不改语义。  
- 非批次报表：目标路径是绑定/模版侧配置项，不是全局导出根下的批号子目录。  
- 触发生成后两类路径行为必须明确可区分、可验收。

## 拟改方向（待实现）

1. **类型标记**：模版或自动结批绑定增加「批次 / 非批次」区分（字段名待定）。  
2. **非批次目标目录**：绑定侧可配置绝对/约定路径；缺省或非法路径时显式失败，禁止 silently 落到批号目录。  
3. **导出调度**：触发后按类型分支——批次 → `根/批号/`；非批次 → `绑定指定目录/`。  
4. **历史报表浏览**：非批次产出是否进「历史报表」根扫描、是否单独入口——待产品补一句。  
5. **单测 / 手测**：两种类型各触发一次，核对路径与文件名。
