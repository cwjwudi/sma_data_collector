# ✅ 已完成：产品口径调整

## 现象（用户反馈）

0.3.146 起「一键隐藏边框」只改**当前选中 sheet / 正文页**。页眉要隐藏边框必须先点到对应页，不符合「一点清掉整份模版所有灰描边」的预期。

## 目标

模版编辑器工具栏「一键隐藏边框」：

- 一次点击处理 **封面 + 正文全部分页 + 封底**
- 覆盖各 sheet 的 **页眉 / 页脚 / 正文控件 / zone 装饰**
- **仍跳过表格**（格线保留）
- **不依赖**当前选中页

版式库三带「一键」语义不变（单版式页即整页）。

# ✅ 已完成：实现

| 项 | 说明 |
|----|------|
| 纯函数 | `hideBordersOnEntireTemplate`（`show-border.ts`） |
| 细粒度 API | `hideBordersOnTemplateSheet` 保留（测试/诊断） |
| UI | `TemplateEditorWorkspace` 按钮改走整模版；提示文案同步 |
| 对抗测 | G3b：封面眉脚+正文多页+封底一次清掉；table 跳过；幂等 |

**验收**：打开含封面/多页正文/封底且页眉有边框的模版 → 停在任意页点「一键隐藏边框」→ 切换到封面/正文页2/封底，非表格灰描边均已无。
